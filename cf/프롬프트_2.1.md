# 병점고 CF 이미지 프롬프트 2.1

Oct 29, 2026

콘티 2.0의 24장 프롬프트를 **뽑는 순서대로** 다시 정리했어요. 위에서부터 차례로 뽑으면 앞 그림을 뒤 그림에 첨부할 수 있어요. 바뀐 곳은 각 그림 아래 **바뀐 점**에 적었어요.

## 쓰는 법

1. 이미지 프롬프트 문서의 **스타일 블록 A**와 **공통 규칙 블록**을 먼저 붙여요.
2. 그 뒤에 아래 프롬프트를 붙여요.
3. \[첨부\]에 적힌 그림을 **적힌 순서대로** 첨부해요. 프롬프트의 "first image", "second image"가 이 순서예요.
4. 모든 프롬프트 끝에 아래 고정 문장이 들어 있어요. 빼지 마세요.

```
Same anime illustration style as the attached images, not a photograph.
```

**뽑을 때마다 확인할 것**: 지우(여, 검은 단발, 노란 머리핀) · 도윤(남, 헝클어진 짙은 갈색 머리) · 교실에 빈자리 없음 · 그림 안에 글자 없음. 글자가 생기면 "remove all text", 실사처럼 나오면 고정 문장을 한 번 더 붙여 다시 뽑아요.
