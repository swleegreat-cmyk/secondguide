# 병점고 CF 콘티 2.0 검토

Oct 29, 2026

콘티 2.0의 시간 계산, 앞에서 심고 뒤에서 거두는 장치, 그림 수, 프롬프트끼리 맞는지를 다시 확인했어요. 큰 틀은 그대로 두면 되고, 촬영(그림 뽑기) 전에 고치면 좋은 것만 모았어요. 고친 프롬프트는 `프롬프트_2.1.md`에 반영했어요.

## 맞는 것

| 항목 | 확인 결과 |
| --- | --- |
| 장면 시간 | 8 + 7 + 6 + 10 + 5 + 4 + 5 = 45초 |
| 비트 시간 | 일곱 장면 모두 비트가 빈틈 없이 이어져요 |
| 아래 자막 | 여섯 줄 (S#1 두 줄, S#2 두 줄, S#4 한 줄, S#6 한 줄). 엔딩 문구는 따로 |
| 새로 뽑을 그림 | N1–N25 중 N3, N22를 뺀 23장 + B14W = 24장 |
| 상상의 문 | S#2→S#3, S#6→S#7 두 곳만. 편집 가이드의 하얀 플래시 0.4초와도 맞아요 |
| 선생님 등장표 | 프롬프트의 옷 색과 모두 맞아요 (감독: 하늘색 셔츠+남색 조끼 남자, 겨자색 카디건 여자, 남색 카디건 여자 / 담임: 검은 안경 남자) |
| 심고 거두기 | 표의 여섯 줄 모두 실제 비트와 그림 번호가 있어요 |

## 고치면 좋은 것

### 꼭 고칠 것

1. **N24 표정 설명이 N9와 달라요.** N9는 "quiet and hopeful"로 뽑는데, N24는 "quiet and uncertain에서 바꿔라"라고 해요. 그림 AI가 이미 희망적인 얼굴을 더 바꾸려다 과하게 웃게 만들 수 있어요. → "조용히 바라보던 얼굴을 눈이 반짝이는 작은 미소로"로 고쳤어요.
2. **S#4 5비트 '문제집을 덮음'과 4비트 '맞았다는 표시' 그림이 없어요.** 체크리스트에 해당 그림이 없어서 편집 때 비게 돼요.
   - 덮는 문제집: N17 프롬프트 앞쪽에 "지우가 문제집을 덮는다"를 넣어 한 장으로 해결했어요. S#5 1비트의 "덮었던 문제집이 다시 펼쳐짐"도 이걸로 이어져요.
   - 맞았다는 표시: 4비트를 N16(1.5초) → N14 위에 빨간 동그라미를 편집으로 그린 화면(1초)으로 나눠 쓰도록 큐시트에 적었어요.
3. **N23 첨부 그림이 다섯 장이에요.** 제미나이는 첨부가 많을수록 얼굴이 섞이기 쉬워요. 이미 다섯 친구가 들어간 **N21**을 기준으로 쓰면 3장(N21, 감독 선생님 3명, 담임)으로 줄어요. N13(4장)도 잘 안 나오면 먼저 두 사람과 친구들만 넣고 뽑은 다음, 그 그림에 선생님을 추가하는 두 단계로 나눠요.
4. **N12는 밤하늘 그림을 첨부하는데 노을이어야 해요.** "하늘을 노을로 바꾸고 별은 없애라"를 프롬프트에 분명히 넣었어요.

### 있으면 좋은 것

5. **엔딩 글씨가 너무 빨라요.** 「다음 반짝임은, 너야」가 0.5초 만에 다음 줄로 넘어가요. 한 줄을 읽는 데 보통 0.8–1초가 필요해요. 처음부터 47초본으로 잡는 걸 권해요(아래 시간표). 45초를 꼭 지켜야 하면 「낮엔 신나게, 밤엔 반짝이게」를 한 번에 띄워 세 박자로 줄여요.

   | | 45초본 (지금) | 47초본 (권장) |
   | --- | --- | --- |
   | 「낮엔 신나게,」 | 0:42.7 | 0:42.7 |
   | 「밤엔 반짝이게」 | 0:43.2 | 0:43.5 |
   | 「다음 반짝임은, 너야」 | 0:43.8 | 0:44.4 |
   | 교표 + 「병점고등학교」 | 0:44.3 | 0:45.6 |
   | 끝 | 0:45.0 | 0:47.0 |

6. **S#6 1비트 1.5초 안에 그림이 두 장이에요(N21 → N22).** N21 0.8초, N22 0.7초로 나누고, N22에서 '띵'과 함께 화면이 뜨게 해요.
7. **S#5 1·2비트가 1.2초, 1.3초로 짧아요.** 왼쪽 위 글씨(「2학년 여름」 「3학년 가을」)는 짧아서 읽히지만, 창문 닫기와 요구르트 동작까지 보이려면 움직임을 거의 주지 말고(크기 108→110%) 그림만 바꾸는 게 좋아요.
8. **N14가 N2와 같은 구도로 나오게** 카메라 높이, 문제집 위치, 연필 각도를 두 프롬프트에 똑같이 적었어요. N2를 뽑을 때부터 맞춰 둬야 S#4의 "어, 아까 그 장면이네?"가 살아요.
9. **모든 프롬프트 끝에 그림체 고정 문장**("Same anime illustration style as the attached images")을 붙였어요. 첨부 그림이 여러 장이면 그림체가 섞이기 쉬워서예요.

### 확인이 필요한 것 (콘티 2.0과 같음)

- **'1지망' 표기**: 병점고가 있는 화성은 경기도 고교평준화 지역이라 학교군 안에서 지망 순위를 적는 방식일 가능성이 높아요. 다만 올해 경기도교육청 고입 전형 요강에서 지원서 양식을 꼭 확인해 주세요.
- **스타일 블록 A와 공통 규칙 블록**: 이 문서에는 들어 있지 않아요. `프롬프트_2.1.md`의 모든 프롬프트도 그 두 블록 뒤에 붙여 써야 해요.
- **실제 병점고 사진**: 교문(N7)과 엔딩에 실제 건물 사진을 함께 첨부하면 재학생들이 알아보기 쉬워요.
