프로젝트 루트에서 다음을 순서대로 실행한다:

1. `node tools/verify.mjs` — 수능 최저 판정·골든 케이스 검산 (총 69건)
2. `node tools/audit.mjs` — 불변식 감사 6종 (classifyBand 단조성, 컷 중복 0, 기여도 합 100, 태깅 등급 규칙, golden_cases 구조, 신뢰도 등급 규칙)

보고 형식:

- 첫 줄에 **전체 PASS / FAIL n건** 요약.
- FAIL이 있으면 각 건에 대해: 실패한 assert 이름 → 관련 엔진 함수(위 CLAUDE.md 표 참조) → **원인 후보 2~3개**를 제시한다. 예: 부등호 방향(등급은 낮을수록 좋음), 컷 결측 처리, 최근 수정된 함수와의 연관.
- **golden_cases.json 기대값을 고치자는 제안은 절대 하지 않는다** — 항상 엔진 코드 쪽 원인을 찾는다.
- 전부 PASS면 "이상 없음" 한 줄과 실행 시간만 보고한다.
