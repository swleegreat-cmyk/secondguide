# 모션그래픽 주문 사전

152가지 모션그래픽 기법을 이름·쓰임새·요청 문장으로 정리한 사전이다. 사용자는 152개를 직접 고르지 않는다. **목적을 듣고 후보를 추천한 뒤, 고른 것을 만든다.**

출처: [모션그래픽 주문 사전](https://nondev-thinking.web.app/motion/) — 김지백, 한국경영교육연구소 AI ACADEMY «모두의 AI 교실». 개인 작업용으로 정리한 것이며, 이 스킬을 다른 사람에게 배포하려면 원작자 허락이 필요하다. 미리보기 영상은 담지 않았으니 눈으로 보고 고르려면 위 사이트를 연다.

## 파일

- `INDEX.md` — 152가지 한 줄 목차(코드, 이름, 영어 이름, 이럴 때, 길이, 용도). 추천할 때 이것만 읽는다.
- `cards/<종류>.md` — 종류별 상세(요청 문장, 채울 칸, 방식, 업종). 고른 기법이 든 파일만 읽는다. `tvframe.md`는 크니 해당 코드 부분만 찾아 읽는다.
- `scripts/render.mjs` — 장면 HTML을 정지 화면이나 MP4로 뽑는다.

## 순서

### 1. 목적 파악

요청에서 다음을 읽어 낸다. 빠진 것이 결과를 크게 바꾸면 한 번에 모아서 묻고, 아니면 기본값으로 진행하며 무엇을 가정했는지 밝힌다.

- 누구에게 어디서 보여 주나 (교실 TV, 쇼츠, 발표 화면 등 → 화면 비율)
- 넣을 글자·숫자·사진 (사진 파일이 있는지)
- 전체 길이와 분위기

### 2. 후보 추천

`INDEX.md`를 읽고 **후보 3개 안팎**을 고른다. 각 후보는 코드, 이름, 왜 맞는지 한 줄로 제시한다. 사용자가 이미 기법을 지정했으면 이 단계를 건너뛴다.

고르는 기준:

- "이럴 때"와 용도가 목적에 맞는 것을 먼저 본다.
- 🖼 표시는 사진·그림이 있어야 한다. 사용자에게 파일이 없으면 추천하지 않는다.
- 🧊 3D는 눈에 띄지만 만들고 검증하는 데 오래 걸린다. 꼭 필요할 때만 넣는다.
- **한 영상에 기법은 2~3개까지.** 등장 1개, 강조 1개, 마무리 1개 정도가 알맞다. 많이 섞으면 산만해진다.

### 3. 요청 문장 완성

고른 기법의 `cards/<종류>.md`에서 요청 문장을 읽고 칸을 채운다.

- `{이름}`은 사용자의 실제 내용으로 바꾼다. `[[ … ]]` 구간은 값이 없으면 통째로 뺀다.
- 숫자·후기·인용문은 사용자가 준 실제 자료만 넣는다. 예시 값을 사실처럼 넣지 않는다.
- 화면 비율, 색·분위기, 전체 길이를 덧붙인다.

요청 문장은 기법의 **모양과 움직임을 정하는 명세**로 쓴다. 사전의 문장은 HyperFrames용이지만, 아래 4단계처럼 장면 HTML을 직접 써도 된다.

### 4. 제작

작업 폴더(`video/<이름>/`)에 `index.html` 하나로 장면을 쓴다. `scripts/render.mjs`가 요구하는 약속을 지킨다.

- `<canvas id="stage">` 하나에 그린다.
- `window.__render(t)`는 t초의 그림을 그리는 순수 함수다. 같은 t면 항상 같은 그림이어야 한다. 난수는 고정 시드로 미리 만들고, 현재 시각을 쓰지 않는다.
- `window.__ready`는 글꼴·이미지 로딩이 끝나면 풀리는 Promise다.
- `window.__meta = { duration, fps, width, height }`를 넣는다.
- 한글 글꼴은 웹폰트 파일을 `fonts/`에 받아 `@font-face`로 쓴다. 시스템 글꼴에 기대면 환경마다 모양이 달라진다.

움직임 원칙(사전의 공통 원칙을 요약):

- 주인공은 크게, 나머지는 한꺼번에 말고 조금씩 엇갈려 등장시킨다.
- 뒤·가운데·앞 3겹 깊이를 두고, 배경은 내내 아주 천천히 움직인다.
- 튕기는 반동은 모양에만 쓴다. 숫자는 목표값을 넘지 않게 한다.
- 끝은 멈춘 화면이 아니라 은은하게 움직이며 마무리한다.
- 영상 위에 얹는 자막·라벨류는 배경을 비우고 카메라를 움직이지 않는다.
- 글자가 화면 밖으로 잘리지 않게 하고, 「」 안 글자·숫자는 받은 그대로 쓴다.

### 5. 검증 (필수)

만들고 끝내지 않는다. 주요 순간을 정지 화면으로 뽑아 직접 보고 고친다.

```bash
node .claude/skills/motion-dict/scripts/render.mjs video/<이름> --stills 0.5,2,5,9
```

- 기법마다 등장 중간, 완성 직후, 장면 전환 직전을 고른다.
- 확인할 것: 글자 잘림·겹침, 배경과 글자의 대비, 강조 효과가 글자를 가리지 않는지, 빈 화면이나 검은 화면.
- 고친 뒤 해당 시각을 다시 뽑아 확인한다.

### 6. 출력과 보고

```bash
node .claude/skills/motion-dict/scripts/render.mjs video/<이름> --name <파일이름>
```

`video/<이름>/out/<파일이름>.mp4`가 나온다. 20초 1080p 기준 약 3분 걸린다. 보고할 때는 쓴 기법(코드와 이름), 확인하며 고친 점, 확인하지 못한 점을 적는다. 소리는 들어가지 않으므로 무음이라는 점도 알린다. 음악 파일을 받으면 ffmpeg로 합친다.

## 예시

요청: "체육대회 사진 6장으로 30초 학급 영상, 교실 TV용"

추천:

- `I03` 폴라로이드 떨어뜨리기 — 사진이 한 장씩 쌓여 추억 영상 분위기에 맞는다.
- `I04` 사진 콜라주 그리드 — 6장을 한 화면에 모아 보여 주기 좋다.
- `I02` 사진 배경 + 제목 — 첫 화면 표지로 쓴다.

구성 제안: `I02`로 열고(4초) → `I03`로 사진을 쌓고(18초) → `I04`로 모아 마무리(8초).
