운동·요리·돈 관리처럼 따라 하는 영상.

요청 문장의 `{이름}`은 채울 칸, `[[ … ]]`는 값이 없으면 통째로 빼는 선택 구간이다.

## H01 운동 인터벌 타이머 (workout interval timer)

- 이럴 때: 홈트·재활 운동·체조 영상, 어르신 건강 교실
- 길이: 운동 길이만큼 · 방식: SVG 선 · 재료: 전부 코드
- 용도: 교육 · 업종: 운동·헬스, 복지·자활, 병원, 유튜버

요청 문장:

```
운동 인터벌 타이머(workout interval timer) 만들어줘. 영상 위에 원형 링 타이머를 얹고, 운동과 휴식을 라운드 수만큼 번갈아 세게. 운동은 주황·휴식은 초록으로 링이 줄어들며 숫자가 1초씩 내려가고, 동작 이름과 라운드(예: 2/5)가 함께 보이게. 운동 시간: 「{work}」. 휴식 시간: 「{rest}」. 라운드: 「{rounds}」.[[ 동작 이름: 「{move}」.]][[ 넣을 영상: {file}.]]
```

칸:

- `{work}` 운동 시간 — 예: 20초
- `{rest}` 휴식 시간 — 예: 10초
- `{rounds}` 라운드 — 예: 5회
- `{move}` 동작 이름 (선택) — 예: 스쿼트

## H02 레시피 단계 카드 (recipe steps)

- 이럴 때: 요리 영상, 반찬 나눔·조리 교육, 특산물 활용 레시피
- 길이: 6~10초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육 · 업종: 음식점, 농업·특산물, 복지·자활, 유튜버

요청 문장:

```
레시피 단계 카드(recipe steps) 만들어줘. 왼쪽 재료 목록이 하나씩 체크되고, 오른쪽에 단계 카드가 사진과 함께 한 장씩 넘어가며 조리 시간 칩이 붙게. 요리 이름: 「{dish}」. 재료: 「{ingr}」. 단계: 「{steps}」.[[ 이미지 파일: {imgs}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{dish}` 요리 이름 — 예: 두부조림
- `{ingr}` 재료 — 예: 두부 1모 / 대파 1대 / 간장 2큰술 / 고춧가루 1큰술
- `{steps}` 단계 — 예: 두부 노릇하게 굽기 5분 / 양념장 부어 끓이기 3분 / 약불로 졸이기 10분
- `{imgs}` 사진 파일들 (선택) — 예: step1.jpg, step2.jpg, step3.jpg
- `{dur}` 지속 시간 (선택) — 예: 8초

## H03 적금·복리 성장 그래프 (savings growth chart)

- 이럴 때: 금융·경제 교육, 자산 형성 지원 사업 안내
- 길이: 5~8초 · 방식: 데이터+SVG 선 · 재료: 전부 코드
- 용도: 교육 · 업종: 금융·보험, 교육, 복지·자활

요청 문장:

```
적금·복리 성장 그래프(savings growth chart) 만들어줘. 매달 넣는 돈이 막대로 쌓이고, 그 위로 이자를 더한 곡선이 그려지며 합계 숫자가 올라가게. 합계는 뒤에 적은 조건을 월복리로 계산해 넣고, 화면 구석에 「세전 · 예시 계산」이라고 작게 적어줘. 매달 넣는 돈: 「{monthly}」. 연 이율: 「{rate}」. 기간: 「{period}」.[[ 지속 시간: {dur}.]]
```

칸:

- `{monthly}` 매달 넣는 돈 — 예: 10만 원
- `{rate}` 연 이율 — 예: 3%
- `{period}` 기간 — 예: 10년
- `{dur}` 지속 시간 (선택) — 예: 6초
