# 보고·데이터 (5)

숫자·추이·비중·일정, 차트·전후 비교.

출처: 모션그래픽 주문 사전 (https://nondev-thinking.web.app/motion/) — 김지백, 한국경영교육연구소 AI ACADEMY «모두의 AI 교실». 2026-11-09 수정본 기준으로 정리.

요청 문장의 `{이름}`은 채울 칸, `[[ … ]]`는 값이 없으면 통째로 빼는 선택 구간이다.

## T06 3D 데이터 도시 (3D data city · 3D bar chart)

- 이럴 때: 연말 결산, 성과 발표, 제안서 영상
- 길이: 10~15초 · 방식: 3D(Three.js) · 재료: 전부 코드
- 용도: 업무 보고, 영업·제안 · 업종: 공공, 제조, IT

요청 문장:

```
3D 데이터 도시(3D bar chart) 만들어줘. 3D는 Three.js로. 자료 파일은 첫 열이 항목 이름, 둘째 열이 숫자인 표 — 숫자가 클수록 높은 빌딩으로, 자료 순서대로 한 줄로 세워줘. 빌딩이 차례로 솟아오른 뒤 카메라가 도시 위로 날아오르며 합계 숫자가 올라가게. 야경에 창문 불빛. 자료 파일: {data}. 무엇의 숫자: 「{what}」.[[ 지속 시간: {dur}.]]
```

칸:

- `{data}` 자료 파일 — 예: data.xlsx
- `{what}` 무엇의 숫자 — 예: 월별 매출
- `{dur}` 지속 시간 (선택) — 예: 15초

## T07 지도 핀 드롭 (map pin drop)

- 이럴 때: 매장·지점 소개, 다녀온 지역 보여주기
- 길이: 6~10초 · 방식: 데이터+SVG 선 · 재료: 전부 코드
- 용도: 홍보, 영업·제안 · 업종: 부동산, 음식점, 공공

요청 문장:

```
지도 핀 애니메이션(map pin drop) 만들어줘. 지도 범위를 점으로 된 지도로 그리고, 주소마다 공개 지도 데이터로 위치를 찾아 그 자리에 핀이 하나씩 떨어지고 물결이 퍼지며, 아래에 개수가 올라가게. 주소 목록 파일: {addr}. 지도 범위: 「{area}」. 개수 이름: 「{label}」.[[ 지속 시간: {dur}.]]
```

칸:

- `{addr}` 주소 목록 파일 — 예: 주소목록.xlsx
- `{area}` 지도 범위 — 예: 대한민국 전체
- `{label}` 개수 이름 — 예: 매장
- `{dur}` 지속 시간 (선택) — 예: 8초

## T08 막대 순위 경주 (bar chart race)

- 이럴 때: 순위 변화, 설문·판매 추이 발표
- 길이: 8~15초 · 방식: 데이터+SVG 선 · 재료: 전부 코드
- 용도: 업무 보고 · 업종: 공공, 쇼핑몰, 유튜버, IT

요청 문장:

```
막대 순위 경주(bar chart race) 만들어줘. 자료 파일은 첫 열이 항목 이름, 맨 윗줄이 기간(연도·월)인 표. 기간 순서대로 막대가 자라며 순위가 바뀌고, 값 숫자도 함께 보이게. 오른쪽 아래 구석에는 지금 기간을 큰 글자로. 자료 파일: {data}.[[ 항목 수: {n}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{data}` 자료 파일 — 예: data.csv
- `{n}` 항목 수 (선택) — 예: 5개
- `{dur}` 지속 시간 (선택) — 예: 10초

## T09 전·후 비교 스플릿 (before/after split)

- 이럴 때: 시술·인테리어·업무 개선 전후 비교
- 길이: 4~6초 · 방식: 데이터+SVG 선 · 재료: 전부 코드
- 용도: 영업·제안, 광고, 업무 보고 · 업종: 뷰티, 병원, 부동산, IT

요청 문장:

```
전·후 비교 스플릿(before/after split) 만들어줘. 왼쪽에 BEFORE, 오른쪽에 AFTER를 놓고, 가운데 흰 선이 좌우로 천천히 움직이며 두 화면을 비교하게. 전: {before}. 후: {after}.[[ 지속 시간: {dur}.]]
```

칸:

- `{before}` 전 사진·영상 — 예: before.jpg
- `{after}` 후 사진·영상 — 예: after.jpg
- `{dur}` 지속 시간 (선택) — 예: 5초

## B10 투표·설문 결과 그래프 (poll results bar)

- 이럴 때: 댓글 투표 결과, 강의 중 설문 결과
- 길이: 3~5초 · 방식: 데이터+글자·CSS · 재료: 전부 코드
- 용도: 업무 보고, 교육 · 업종: 유튜버, 교육, 공공

요청 문장:

```
투표 결과 그래프(poll results bar) 만들어줘. 보기들이 막대로 차오르며 %가 올라가게. 제목: 「{title}」. 보기와 수치: 「{opts}」.[[ 지속 시간: {dur}.]]
```

칸:

- `{title}` 제목 — 예: 여러분의 선택은?
- `{opts}` 보기와 수치 — 예: A 바로 써본다 62% / B 좀 더 배운다 27% / C 아직 모르겠다 11%
- `{dur}` 지속 시간 (선택) — 예: 5초
