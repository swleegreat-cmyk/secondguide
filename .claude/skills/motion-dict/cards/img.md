# 내 이미지 넣기 (10)

사진 한 장이 배경·인서트가 되는 장면.

출처: 모션그래픽 주문 사전 (https://nondev-thinking.web.app/motion/) — 김지백, 한국경영교육연구소 AI ACADEMY «모두의 AI 교실». 2026-11-09 수정본 기준으로 정리.

요청 문장의 `{이름}`은 채울 칸, `[[ … ]]`는 값이 없으면 통째로 빼는 선택 구간이다.

## I01 켄 번스 줌 배경 (Ken Burns effect)

- 이럴 때: 인트로 배경, 매장·풍경 소개, 사진만 있는 장면
- 길이: 5~10초 · 방식: 글자·CSS · 재료: 내 사진·그림 필요
- 용도: 홍보, 광고 · 업종: 음식점, 부동산, 뷰티, 유튜버

요청 문장:

```
켄 번스 효과(Ken Burns effect) 사진 배경 만들어줘. 사진이 천천히 확대되며 한쪽으로 흘러가게. 이미지 파일: {img}.[[ 움직임: {move}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{img}` 이미지 파일 — 예: photo.jpg
- `{move}` 움직임 (선택) — 예: 천천히 확대하며 오른쪽으로
- `{dur}` 지속 시간 (선택) — 예: 8초

## I02 사진 배경 + 제목 (photo title card)

- 이럴 때: 챕터 표지, 행사·매장 소개 첫 화면
- 길이: 3~6초 · 방식: 글자·CSS · 재료: 내 사진·그림 필요
- 용도: 홍보, 광고 · 업종: 공공, 음식점, 유튜버

요청 문장:

```
사진 배경 타이틀(photo title card) 만들어줘. 사진이 점점 흐려지고 어두워지며 가운데로 제목이 올라오게. 이미지 파일: {img}. 제목: 「{title}」.[[ 작은 글자: 「{sub}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{img}` 이미지 파일 — 예: photo.jpg
- `{title}` 제목 — 예: 오늘의 주제
- `{sub}` 작은 글자 (선택) — 예: 2026 가을 특강
- `{dur}` 지속 시간 (선택) — 예: 5초

## I03 폴라로이드 떨어뜨리기 (polaroid drop)

- 이럴 때: 행사 스케치, 수강생·고객 사진 모음
- 길이: 4~6초 · 방식: 글자·CSS · 재료: 내 사진·그림 필요
- 용도: 홍보, 광고 · 업종: 교육, 음식점, 뷰티, 유튜버

요청 문장:

```
폴라로이드 사진 떨어뜨리기(polaroid drop) 만들어줘. 흰 테두리 사진이 한 장씩 위에서 툭툭 떨어져 살짝 기울어진 채 쌓이게. 이미지 파일: {imgs}.[[ 사진 아래 손글씨: 「{cap}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{imgs}` 이미지 파일들 — 예: photo1.jpg / photo2.jpg / photo3.jpg
- `{cap}` 사진 아래 손글씨 (선택) — 예: 2026 봄 워크숍
- `{dur}` 지속 시간 (선택) — 예: 5초

## I04 사진 콜라주 그리드 (bento photo collage)

- 이럴 때: 포트폴리오, 메뉴·상품 모음, 행사 하이라이트
- 길이: 4~6초 · 방식: 글자·CSS · 재료: 내 사진·그림 필요
- 용도: 홍보, 광고 · 업종: 음식점, 쇼핑몰, 뷰티, 부동산

요청 문장:

```
사진 콜라주 그리드(bento photo collage) 만들어줘. 크기가 다른 칸들에 사진이 차례로 톡톡 채워지고 전체가 천천히 확대되게. 이미지 파일: {imgs}.[[ 가운데 제목: 「{title}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{imgs}` 이미지 파일들 — 예: a.jpg / b.jpg / c.jpg / d.jpg / e.jpg
- `{title}` 가운데 제목 (선택) — 예: 우리 가게 대표 메뉴
- `{dur}` 지속 시간 (선택) — 예: 5초

## I05 3D 사진 카드 기울이기 (3D tilt photo card)

- 이럴 때: 대표 사진·상품·자격증 소개
- 길이: 3~5초 · 방식: 3D(Three.js) · 재료: 내 사진·그림 필요
- 용도: 홍보, 광고 · 업종: 쇼핑몰, 뷰티, IT

요청 문장:

```
3D 사진 카드(3D tilt card) 만들어줘. 짙은 남색 배경 가운데에 모서리가 둥근 사진 카드(화면 폭의 절반쯤)가 공중에 떠서, 좌우로 살짝만(20도 안쪽) 천천히 기울었다 돌아오고 위아래로도 살짝 끄덕이게. 카드가 기울 때 표면에 비스듬한 흰 빛줄기가 한 번 쓱 지나가게. 이미지 파일: {img}.[[ 카드 아래 글자: 「{title}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{img}` 이미지 파일 — 예: photo.jpg
- `{title}` 카드 아래 글자 (선택) — 예: 신메뉴 출시
- `{dur}` 지속 시간 (선택) — 예: 4초


칸:

- `{imgs}` 이미지 파일들 — 예: photo1.jpg / photo2.jpg / photo3.jpg / photo4.jpg
- `{dur}` 지속 시간 (선택) — 예: 8초

## I08 휴대폰 화면 목업 (phone mockup)

- 이럴 때: 홈페이지·앱·예약 화면 소개
- 길이: 4~8초 · 방식: 글자·CSS · 재료: 내 사진·그림 필요
- 용도: 홍보, 영업·제안 · 업종: IT, 쇼핑몰, 음식점

요청 문장:

```
기기 화면 목업(device mockup) 만들어줘. 휴대폰 화면 안에 캡처 화면이 들어가 위로 천천히 스크롤되고, 기기가 살짝 기울며 떠 있게. 화면 이미지: {img}.[[ 기기: {device}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{img}` 화면 캡처 파일 — 예: screenshot.png
- `{device}` 기기 (선택) — 예: 노트북
- `{dur}` 지속 시간 (선택) — 예: 6초

## I09 글자 속 사진 (image in text mask)

- 이럴 때: 오프닝 타이틀, 여행·계절 테마
- 길이: 3~5초 · 방식: 글자·CSS · 재료: 내 사진·그림 필요
- 용도: 홍보, 광고 · 업종: 유튜버, 뷰티, 음식점, 쇼핑몰

요청 문장:

```
글자 모양 안에 사진이 보이는 마스크(image text mask) 만들어줘. 큰 글자 속에서 사진이 천천히 흐르다가, 글자가 커지며 사진 전체가 드러나게. 이미지 파일: {img}. 글자: 「{word}」.[[ 지속 시간: {dur}.]]
```

칸:

- `{img}` 이미지 파일 — 예: photo.jpg
- `{word}` 글자 — 예: SUMMER
- `{dur}` 지속 시간 (선택) — 예: 4초

칸:

- `{img}` 이미지 파일 — 예: photo.jpg
