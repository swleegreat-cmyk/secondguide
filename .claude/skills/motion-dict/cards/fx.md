# 효과·오브젝트 (4)

분위기를 살리는 효과와 떠다니는 물체.

출처: 모션그래픽 주문 사전 (https://nondev-thinking.web.app/motion/) — 김지백, 한국경영교육연구소 AI ACADEMY «모두의 AI 교실». 2026-11-09 수정본 기준으로 정리.

요청 문장의 `{이름}`은 채울 칸, `[[ … ]]`는 값이 없으면 통째로 빼는 선택 구간이다.

## T02 제품 360° 턴테이블 (3D product turntable)

- 이럴 때: 교재·굿즈·상품 소개
- 길이: 5~8초 · 방식: 3D(Three.js) · 재료: AI 영상 생성이 더 나음
- 용도: 광고, 홍보 · 업종: 쇼핑몰, 제조, 뷰티

요청 문장:

```
제품 360° 턴테이블(3D product turntable) 만들어줘. 3D는 Three.js로. 제품이 반사 바닥 위에서 천천히 한 바퀴 돌게. 스튜디오 조명. 제품 사진·표지 파일: {item}.[[ 지속 시간: {dur}.]]
```

칸:

- `{item}` 제품 사진·표지 파일 — 예: cover.png
- `{dur}` 지속 시간 (선택) — 예: 6초

## T18 3D 떠다니는 아이콘 (floating 3D icons)

- 이럴 때: 챕터 전환, 썸네일 배경
- 길이: 5~8초 · 방식: 3D(Three.js) · 재료: 전부 코드
- 용도: 홍보 · 업종: IT, 공공, 쇼핑몰

요청 문장:

```
3D 아이콘들이 공중에 떠서 둥실둥실 도는 인서트(floating 3D icons) 만들어줘. 3D는 Three.js로. 아이콘: 「{icons}」.[[ 배경: {bg}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{icons}` 아이콘 — 예: 문서 / 폴더 / 메일 / 차트 / 톱니바퀴
- `{bg}` 배경 (선택) — 예: 밝은 파스텔
- `{dur}` 지속 시간 (선택) — 예: 6초

## B06 이모지 폭죽 (emoji burst · confetti)

- 이럴 때: 성공·축하·이벤트 당첨 장면
- 길이: 1~2초 · 방식: 3D(Three.js)+물리 · 재료: 전부 코드
- 용도: 홍보, 광고 · 업종: 유튜버, 쇼핑몰, 음식점

요청 문장:

```
이모지 폭죽(emoji burst) 만들어줘. 이모지가 화면 가운데서 팡 터져 3D로 흩어지며 떨어지게. 배경은 투명하게. 이모지: {emo}.[[ 넣을 영상: {file}.]][[ 시작 시점: {at}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{emo}` 이모지 — 예: 🎉 👏 ✨
- `{at}` 시작 시점 (선택) — 예: 2:40
- `{dur}` 지속 시간 (선택) — 예: 2초

## B04 집중선 + 화면 흔들림 (speed lines · camera shake)

- 이럴 때: 반전·충격 리액션
- 길이: 0.5~1초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보, 광고 · 업종: 유튜버, 쇼핑몰, 음식점

요청 문장:

```
집중선(speed lines)과 화면 흔들림(camera shake) 넣어줘. 순간 화면이 인물 쪽으로 1.2배 확 당겨지며 흰 빛이 짧게 번쩍하고, 만화 집중선이 얼굴을 향해 쏟아지게. 화면 흔들림은 처음에만 잠깐 떨다 잦아들며 멈추고, 끝에 모두 한꺼번에 사라지며 화면이 원래 크기로 돌아오게.[[ 함께 띄울 글자: 「{text}」.]][[ 넣을 영상: {file}.]][[ 시작 시점: {at}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{text}` 함께 띄울 글자 (선택) — 예: !!
- `{at}` 시작 시점 (선택) — 예: 1:15
- `{dur}` 지속 시간 (선택) — 예: 1.5초
