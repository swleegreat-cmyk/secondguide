## M01 도시 소개 3D 비행 (city flyover)

- 이럴 때: 지역·관광 소개 영상의 첫 장면, 우리 동네 명소 소개
- 길이: 6~10초 · 방식: 3D(Three.js) · 재료: AI 영상 생성이 더 나음
- 용도: 홍보 · 업종: 관광·지역, 부동산, 공공, 숙박

요청 문장:

```
도시 소개 3D 비행 영상(city flyover) 만들어줘. 3D는 Three.js로. 실제 지도 모양이 아니라 블록 건물·도로·나무로 된 미니어처 세트로 도시를 만들고, 명소는 눈에 띄는 건물로 따로 세워줘. 카메라가 곡선을 그리며 날아가다 명소를 지날 때마다 이름표가 떠오르고, 도시 이름은 화면 구석에 제목으로 띄우게. 도시 이름: 「{city}」. 명소: 「{spots}」.[[ 지속 시간: {dur}.]]
```

칸:

- `{city}` 도시 이름 — 예: ○○시
- `{spots}` 명소 3곳 — 예: ○○역 / 시청 / 전통시장
- `{dur}` 지속 시간 (선택) — 예: 8초

## M02 우리 지역으로 확대 + 동그라미 (map zoom-in highlight)

- 이럴 때: 사업 대상 지역·센터 위치·관할 구역 소개
- 길이: 5~8초 · 방식: SVG 선 · 재료: 전부 코드
- 용도: 홍보 · 업종: 공공, 관광·지역, 복지·자활, 병원

요청 문장:

```
지도 확대 강조 애니메이션(map zoom-in highlight) 만들어줘. 처음엔 주변 구역이 모두 보이는 넓은 지도(그 지역이 속한 도나 시 전체)로 시작해, 한 지역으로 부드럽게 확대되고 그 지역만 밝아진 뒤 빨간 손그림 동그라미가 그려지며 이름표가 톡 붙게. 지도는 무료로 쓸 수 있는 공개 지도 데이터로 그리고 출처는 화면 구석에 작게 적어줘. 지역 이름: 「{area}」.[[ 한 줄 설명: 「{desc}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{area}` 지역 이름 — 예: ○○시
- `{desc}` 한 줄 설명 (선택) — 예: 우리 센터가 있는 곳
- `{dur}` 지속 시간 (선택) — 예: 6초

요청 문장:

```
찾아오는 길 경로 애니메이션(route line animation) 만들어줘. 단순한 거리 지도 위에 출발지에서 도착지까지 길이 선으로 그려지고, 작은 사람 점이 따라가며 도착하면 걸리는 시간 칩이 붙게. 지도는 무료로 쓸 수 있는 공개 지도 데이터로 그리고 출처는 화면 구석에 작게 적어줘. 출발: 「{from}」. 도착: 「{to}」. 걸리는 시간: 「{time}」.[[ 지속 시간: {dur}.]]
```

칸:

- `{from}` 출발 장소 — 예: ○○역 2번 출구
- `{to}` 도착 장소 — 예: 우리 가게
- `{time}` 걸리는 시간 — 예: 도보 5분
- `{dur}` 지속 시간 (선택) — 예: 6초

## M04 명소 핀 투어 + 사진 카드 (map pin tour)

- 이럴 때: 관광 코스·축제장·맛집 투어 소개
- 길이: 8~12초 · 방식: SVG 선 · 재료: 내 사진·그림 필요
- 용도: 홍보 · 업종: 관광·지역, 숙박, 행사·축제, 음식점

요청 문장:

```
지도 핀 투어 애니메이션(map pin tour) 만들어줘. 지도 위에 번호 핀 세 개가 떨어지고, 카메라가 핀에서 핀으로 차례로 옮겨 가며 확대하면 핀마다 그 장소 사진 카드가 튀어 올라 이름을 보여 주게. 핀과 핀 사이는 점선으로 이어줘. 지도는 무료로 쓸 수 있는 공개 지도 데이터로 그리고 출처는 화면 구석에 작게 적어줘. 장소: 「{spots}」. 사진 파일들(장소 순서대로): {imgs}.[[ 지속 시간: {dur}.]]
```

칸:

- `{spots}` 장소 3곳 — 예: ○○호수 공원 / 야경 전망대 / 카페 거리
- `{imgs}` 사진 파일들 — 예: photo1.jpg, photo2.jpg, photo3.jpg
- `{dur}` 지속 시간 (선택) — 예: 10초

## M05 노선도식 코스 안내 (transit-style course map)

- 이럴 때: 관광 코스·행사 동선·교육 과정 순서 안내
- 길이: 6~10초 · 방식: SVG 선 · 재료: 전부 코드
- 용도: 홍보 · 업종: 관광·지역, 행사·축제, 공공

요청 문장:

```
노선도식 코스 안내 애니메이션(transit-style course map) 만들어줘. 지하철 노선도처럼 45도로 꺾이는 굵은 회색 선 위에 코스마다 역 동그라미와 1코스·2코스 번호·이름을 놓고, 작은 열차가 선을 따라 달리면 지나간 구간에 색이 차오르게. 열차가 역마다 잠깐 멈출 때 역 동그라미가 톡 커지며 불이 켜지고 이름표도 진해지게, 마지막 역에서는 열차가 선 채 끝까지 머무르게. 코스 순서: 「{stops}」.[[ 제목: 「{title}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{stops}` 코스 순서 — 예: 전통시장 → 공원 → 전망대
- `{title}` 제목 (선택) — 예: ○○시 반나절 코스
- `{dur}` 지속 시간 (선택) — 예: 8초

- 길이: 6~10초 · 방식: 3D(Three.js) · 재료: 전부 코드
- 용도: 홍보 · 업종: 병원, 쇼핑몰, 공공

요청 문장:

```
3D 층별 안내 애니메이션(floor directory) 만들어줘. 3D는 Three.js로. 반투명한 건물 층판이 위아래로 벌어지며 떠오르고, 층마다 옆으로 선을 이어 이름표를 붙인 뒤 강조할 층이 빛나며 그 이름표가 커지게. 카메라는 천천히 돌게. 층별 이름: 「{floors}」.[[ 강조할 층: 「{focus}」.]][[ 지속 시간: {dur}.]]

## M07 3D 지형 둘레길·등산 코스 (terrain trail flyover)

- 이럴 때: 둘레길·등산로·걷기 행사 코스 소개
- 길이: 8~15초 · 방식: 3D(Three.js) · 재료: 전부 코드
- 용도: 홍보 · 업종: 관광·지역, 공공, 운동·헬스

요청 문장:

```
3D 지형 코스 비행 영상(terrain trail flyover) 만들어줘. 3D는 Three.js로. 「{place}」 일대의 산이 솟고 골짜기가 파인 지형 위에 코스 선이 출발점부터 그려지고, 카메라가 그 길을 따라 날아가며 아래 높이 그래프의 현재 위치 점도 함께 움직이게. 지형은 공개 고도 데이터로(없으면 예시 지형), 코스는 GPX 파일대로(없으면 예시 코스로 그리고 «예시»라고 작게 표시). 지도는 무료로 쓸 수 있는 공개 지도 데이터로 그리고 출처는 화면 구석에 작게 적어줘. 코스 이름: 「{name}」. 거리: 「{dist}」.[[ 소요 시간: 「{time}」.]][[ 코스 기록 파일: {gpx}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{name}` 코스 이름 — 예: ○○산 둘레길 1코스
- `{place}` 지역(산 이름) — 예: ○○산
- `{dist}` 거리 — 예: 4.2km
- `{time}` 소요 시간 (선택) — 예: 약 2시간
- `{gpx}` 코스 기록 파일(GPX) (선택) — 예: course.gpx
- `{dur}` 지속 시간 (선택) — 예: 10초

## M08 날씨 안내 카드 (weather forecast card)

- 이럴 때: 행사 당일 안내, 관광 영상, 농사 소식
- 길이: 5~8초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보 · 업종: 관광·지역, 농업·특산물, 행사·축제, 유튜버

요청 문장:

```
날씨 안내 카드(weather forecast card) 만들어줘. 왼쪽 위에 지역 이름이 뜨고, 그 아래 날씨에 맞는 큰 그림이 움직이고(해는 빛살이 돌고, 구름은 흘러가고, 비는 빗방울이 떨어지게), 옆에서 기온 숫자가 굴러 올라가 멈춘 뒤, 아래에 3일 예보 칸이 왼쪽부터 한 칸씩 붙게 — 이 순서대로. 날씨는 인터넷에서 불러오지 말고 내가 적은 값 그대로 써줘. 지역: 「{place}」. 기온: 「{temp}」. 날씨: 「{sky}」. 3일 예보: 「{days}」.
```

칸:

- `{place}` 지역 — 예: ○○시
- `{temp}` 기온 — 예: 23°
- `{sky}` 날씨 — 예: 맑고 구름 조금
- `{days}` 3일 예보 — 예: 내일 맑음 25° / 모레 비 19° / 글피 구름 21°

```
우리 지역 소개 카드(region fact card) 만들어줘. 배경 사진이 천천히 확대되고(사진이 없으면 은은한 색 배경) 그 위에 지역 이름이 크게 뜬 뒤, 아래에 네 칸이 그림 아이콘과 함께 하나씩 톡톡 나타나게. 글자가 잘 읽히게 사진 위에 어두운 막을 깔아줘. 지역 이름: 「{place}」. 네 칸 내용: 「{facts}」.[[ 배경 이미지 파일: {img}.]]

## M11 역세권 거리 링 (distance rings)

- 이럴 때: 매물·학원·매장 위치 장점 소개
- 길이: 5~8초 · 방식: SVG 선 · 재료: 전부 코드
- 용도: 영업·제안, 홍보 · 업종: 부동산, 교육, 음식점, 숙박

요청 문장:

```
거리 동심원 애니메이션(distance rings) 만들어줘. 동네 지도 가운데 핀에서 시간별 동그라미가 차례로 퍼지고, 동그라미마다 걸리는 시간 칩과 그 안의 주변 장소 점·이름이 하나씩 나타나게. 동그라미 크기는 지도 축척에 맞춰 걷는 거리로 잡아줘. 지도는 무료로 쓸 수 있는 공개 지도 데이터로 그리고 출처는 화면 구석에 작게 적어줘. 가운데 장소: 「{center}」. 시간 링: 「{rings}」.[[ 주변 장소: 「{near}」.]]
```

칸:

- `{center}` 가운데 장소 — 예: 우리 가게(○○시 ○○동)
- `{rings}` 시간 링 — 예: 도보 5분 / 10분 / 15분
- `{near}` 주변 장소 (선택) — 예: ○○역 / ○○초등학교 / ○○공원
