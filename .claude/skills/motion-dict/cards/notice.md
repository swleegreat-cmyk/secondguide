요청 문장의 `{이름}`은 채울 칸, `[[ … ]]`는 값이 없으면 통째로 빼는 선택 구간이다.

## N01 안전 수칙 픽토그램 (safety pictograms)

- 이럴 때: 현장 안전 교육, 시설 이용 안내, 위생 수칙
- 길이: 5~8초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육 · 업종: 공공, 제조, 복지·자활

요청 문장:

```
안전 수칙 픽토그램(safety pictograms) 만들어줘. 수칙마다 단순한 사람 그림 타일이 이름과 함께 하나씩 올라오고, 지킬 일에는 초록 ⭕, 하지 말아야 할 일에는 빨간 ❌ 도장이 쾅 찍히며 타일이 살짝 흔들리게. 수칙 목록: 「{rules}」.[[ 제목: 「{title}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{rules}` 수칙 목록 — 예: 안전모 쓰기 ⭕ / 뛰지 않기 ❌ / 손 씻기 ⭕ / 비상구 확인 ⭕
- `{title}` 제목 (선택) — 예: 현장 안전 수칙
- `{dur}` 지속 시간 (선택) — 예: 6초

## N02 신청 절차 흐름도 (application process flow)

- 이럴 때: 지원금·바우처·서비스 신청 방법 안내
- 길이: 5~8초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육, 홍보 · 업종: 공공, 복지·자활, 금융·보험, 법률·세무

요청 문장:

```
신청 절차 흐름도(application process flow) 만들어줘. 번호 붙은 단계 상자가 화살표로 하나씩 이어지며 그려지고, 서류 아이콘이 상자를 차례로 옮겨 가면 지금 단계는 진하게 빛나고 지난 단계에는 ✓ 표시가 붙게. 단계: 「{steps}」.[[ 화살표 옆 기간 칩: 「{days}」.]][[ 제목: 「{title}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{steps}` 단계 — 예: 서류 준비 / 접수 / 심사 / 결과 안내
- `{days}` 단계 사이 걸리는 기간 (선택) — 예: 1일 / 3일 / 7일
- `{title}` 제목 (선택) — 예: ○○ 지원금 신청 절차
- `{dur}` 지속 시간 (선택) — 예: 6초

## N03 채용 공고 카드 (hiring announcement)

- 이럴 때: 직원·강사·자원봉사자 모집 공고
- 길이: 5~8초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보 · 업종: 복지·자활, 병원, 제조, 공공, 음식점

요청 문장:

```
채용 공고 카드(hiring announcement) 만들어줘. 맨 위 기관 이름 딱지 아래로 「함께할 분을 찾습니다」 제목이 뜨고, 모집 분야·근무 조건·마감일 칩이 차례로 톡톡 올라온 뒤 맨 아래 지원 방법 띠가 왼쪽부터 펼쳐지게. 기관: 「{org}」. 모집 분야: 「{role}」. 근무 조건: 「{cond}」. 마감일: 「{due}」.[[ 지원 방법: 「{how}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{org}` 기관 — 예: ○○복지관
- `{role}` 모집 분야 — 예: 사회복지사 1명
- `{cond}` 근무 조건 — 예: 주 5일 · 9시~18시
- `{due}` 마감일 — 예: 10월 31일
- `{how}` 지원 방법 (선택) — 예: 이메일·방문 접수 · 문의 02-000-0000
- `{dur}` 지속 시간 (선택) — 예: 6초

## N04 조직도 펼치기 (org chart)

- 이럴 때: 기관 소개, 신입 직원 안내, 사업 설명회
- 길이: 5~8초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 업무 보고, 교육 · 업종: 공공, 복지·자활, 제조

요청 문장:

```
조직도 펼치기(org chart) 만들어줘. 맨 위 상자에서 가지선이 쭉 그려지며 아래 팀 상자, 그 아래 담당 상자가 차례로 톡톡 펼쳐지게. 팀마다 색을 달리해 한눈에 구분되게 해줘. 조직 구조: 「{tree}」.[[ 제목: 「{title}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{tree}` 조직 구조 — 예: 센터장 > 사업팀(사례관리·일자리) / 교육팀(직업교육·상담) / 행정팀(회계·시설)
- `{title}` 제목 (선택) — 예: ○○센터 조직도
- `{dur}` 지속 시간 (선택) — 예: 6초

## N05 인증·수상 배지 벽 (awards & certifications wall)

- 이럴 때: 기관·회사 소개, 믿음을 주고 싶을 때
- 길이: 4~6초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 영업·제안, 홍보 · 업종: 병원, 제조, 공공

요청 문장:

```
인증·수상 배지 벽(awards & certifications wall) 만들어줘. 어두운 벽의 격자 칸에 둥근 배지와 방패 배지가 이름표와 함께 하나씩 걸리며 살짝 흔들리고, 걸린 배지마다 광택이 한 번씩 스쳐 지나가게. 인증·수상 목록: 「{awards}」.[[ 한 칸은 금테 액자로 만들어 사진을 넣어줘. 이미지 파일: {img}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{awards}` 인증·수상 목록 — 예: 우수기관 인증 / 안전 인증 / 고객만족 대상
- `{img}` 액자에 넣을 사진 (선택) — 예: award.jpg
- `{dur}` 지속 시간 (선택) — 예: 5초

## N06 모금·목표 달성 온도계 (goal thermometer)

- 이럴 때: 모금·후원 캠페인, 참여 목표 알리기
- 길이: 5~8초 · 방식: SVG 선 · 재료: 전부 코드
- 용도: 홍보, 업무 보고 · 업종: 복지·자활, 공공, 행사·축제

요청 문장:

```
모금·목표 달성 온도계(goal thermometer) 만들어줘. 눈금이 있는 온도계 속 빨간 막대가 아래에서 위로 현재 값까지 차오르며 모인 값과 퍼센트 숫자가 함께 올라가고, 막대가 멈추면 「목표까지 ○%」 칩이 반짝이며 튀어나오게. 목표: 「{goal}」. 현재: 「{now}」.[[ 캠페인 이름: 「{title}」.]][[ 단위: {unit}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{goal}` 목표 — 예: 1,000만 원
- `{now}` 현재 — 예: 780만 원
- `{title}` 캠페인 이름 (선택) — 예: 이웃 사랑 나눔 모금
- `{unit}` 단위(돈이 아닐 때) (선택) — 예: 봉사 시간
- `{dur}` 지속 시간 (선택) — 예: 6초

## N07 사람 아이콘 통계 (people pictogram)

- 이럴 때: 조사 결과·통계 발표, 캠페인·정책 설명
- 길이: 4~6초 · 방식: SVG 선+데이터 · 재료: 전부 코드
- 용도: 업무 보고, 교육 · 업종: 공공, 복지·자활, 병원

요청 문장:

```
사람 아이콘 통계(people pictogram) 만들어줘. 사람 아이콘 100개(10×10 격자) 중 해당 비율만큼 하나씩 빨갛게 칠해지고, 옆에 퍼센트 숫자가 올라가며 설명과 「10명 중 ○명」 문구가 붙게. 전체: 「{total}」. 해당 인원: 「{part}」. 설명: 「{desc}」.[[ 출처(화면 아래 작게): 「{src}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{total}` 전체 — 예: 100명
- `{part}` 해당 인원 — 예: 23명
- `{desc}` 설명 — 예: 교육 뒤 취업한 참여자
- `{src}` 출처 (선택) — 예: ○○센터 2025년 참여자 조사
- `{dur}` 지속 시간 (선택) — 예: 5초

## N08 FAQ 카드 넘기기 (FAQ flip cards)

- 이럴 때: 자주 묻는 질문, 이용 안내, 제도 설명
- 길이: 6~10초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육, 홍보 · 업종: 공공, 병원, 쇼핑몰, 법률·세무

요청 문장:

```
FAQ 카드 넘기기(FAQ flip cards) 만들어줘. 질문 카드 더미에서 맨 위 카드가 가로로 뒤집히며 뒷면의 답이 보이고, 옆으로 빠지면 다음 질문 카드가 더미에서 올라오게. 앞면은 진한 색에 질문, 뒷면은 흰 바탕에 답. 질문과 답 1: 「{qa1}」. 질문과 답 2: 「{qa2}」.[[ 질문과 답 3: 「{qa3}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{qa1}` 질문과 답 1 — 예: 신청은 어디서 하나요? → 가까운 주민센터나 온라인으로 신청해요.
- `{qa2}` 질문과 답 2 — 예: 준비 서류는 뭔가요? → 신분증과 신청서 한 장이면 돼요.
- `{qa3}` 질문과 답 3 (선택) — 예: 비용이 드나요? → 무료예요.
- `{dur}` 지속 시간 (선택) — 예: 9초
