# 가게·서비스 안내 (9)

메뉴·가격·영업시간·예약·매물.

출처: 모션그래픽 주문 사전 (https://nondev-thinking.web.app/motion/) — 김지백, 한국경영교육연구소 AI ACADEMY «모두의 AI 교실». 2026-11-09 수정본 기준으로 정리.

요청 문장의 `{이름}`은 채울 칸, `[[ … ]]`는 값이 없으면 통째로 빼는 선택 구간이다.

## S01 메뉴판 보드 (animated menu board)

- 이럴 때: 매장 TV 메뉴판, 가게 소개 영상, 신메뉴 안내
- 길이: 5~7초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 광고, 영업·제안 · 업종: 음식점, 뷰티, 쇼핑몰, 숙박

요청 문장:

```
메뉴판 보드(animated menu board) 만들어줘. 어두운 칠판 느낌의 보드에 메뉴 이름과 가격이 점선으로 이어진 채 한 줄씩 미끄러져 들어오고, 추천 메뉴에는 사진 카드와 「추천」 배지가 반짝이게. 제목: 「{title}」. 메뉴와 가격: 「{menu}」.[[ 추천 메뉴: 「{best}」.]][[ 이미지 파일: {img}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{title}` 메뉴판 제목 — 예: 오늘의 메뉴
- `{menu}` 메뉴와 가격 — 예: 아메리카노 4,000원 / 카페라테 4,500원 / 유자차 5,000원
- `{best}` 추천 메뉴 (선택) — 예: 카페라테
- `{img}` 이미지 파일 (선택) — 예: latte.jpg
- `{dur}` 지속 시간 (선택) — 예: 6초

## S02 영업시간·휴무 안내 (business hours)

- 이럴 때: 병원·가게·센터 영업시간 안내, 명절 휴무 공지
- 길이: 4~6초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보 · 업종: 병원, 음식점, 공공, 뷰티, 법률·세무

요청 문장:

```
영업시간 안내 카드(business hours) 만들어줘. 월~일 요일 칸 7개가 차례로 켜지며 요일마다 여는 시간이 적히고, 오늘 요일은 맥박 치듯 강조되게. 쉬는 날은 회색 칸에 「휴무」라고 적어 줘. 제목: 「{title}」. 영업시간: 「{hours}」.[[ 점심시간: 「{lunch}」.]][[ 휴무일: 「{off}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{title}` 제목 — 예: ○○의원 진료 시간 안내
- `{hours}` 영업시간 — 예: 평일 09:00~18:00, 토요일 09:00~13:00
- `{lunch}` 점심시간 (선택) — 예: 12:30~13:30
- `{off}` 휴무일 (선택) — 예: 일요일·공휴일
- `{dur}` 지속 시간 (선택) — 예: 5초

## S03 요금제 3단 비교 (pricing tiers)

- 이럴 때: 수강료·회원권·이용 요금 안내
- 길이: 4~6초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 영업·제안, 광고 · 업종: 교육, 운동·헬스, IT, 뷰티

요청 문장:

```
요금제 3단 비교(pricing tiers) 만들어줘. 요금제 카드 3장이 아래에서 올라오고, 추천 요금제는 가운데에 더 크게 놓고 「추천」 배지를 달아 줘. 포함 내용에는 체크가 차례로 켜지고 가격 숫자는 0부터 올라가게. 제목: 「{title}」. 요금제: 「{plans}」.[[ 추천 요금제: 「{best}」.]][[ 포함 내용: 「{incl}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{title}` 제목 — 예: 수강료 안내
- `{plans}` 요금제 3개 — 예: 기본 월 3만 원 / 표준 월 5만 원 / 프리미엄 월 8만 원
- `{best}` 추천 요금제 (선택) — 예: 표준
- `{incl}` 포함 내용 (선택) — 예: 기본: 주 2회 수업 / 표준: 주 3회 + 개인 상담 / 프리미엄: 매일 수업 + 1:1 코칭
- `{dur}` 지속 시간 (선택) — 예: 5초

## S04 쿠폰·도장 적립 (coupon & stamp card)

- 이럴 때: 단골 이벤트, 첫 방문 혜택, 적립 제도 안내
- 길이: 4~6초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 광고, 영업·제안 · 업종: 음식점, 뷰티, 쇼핑몰, 운동·헬스

요청 문장:

```
쿠폰·도장 적립 카드(coupon & stamp card) 만들어줘. 쿠폰이 점선을 따라 톡 뜯기며 혜택이 보이고, 옆의 적립 카드 칸에 도장이 하나씩 쾅 찍힐 때마다 카드가 살짝 흔들리게. 마지막 칸에는 선물 아이콘을 넣어 줘. 혜택: 「{gift}」. 모을 도장 개수: 「{count}」.[[ 기간: 「{period}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{gift}` 혜택 — 예: 음료 1잔 무료
- `{count}` 모을 도장 개수 — 예: 10개
- `{period}` 기간 (선택) — 예: 10월 31일까지
- `{dur}` 지속 시간 (선택) — 예: 5초

## S05 예약 3단계 안내 (booking steps)

- 이럴 때: 진료·상담·시술 예약 방법 안내
- 길이: 5~7초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보, 영업·제안 · 업종: 병원, 뷰티, 숙박, 법률·세무

요청 문장:

```
예약 3단계 안내(booking steps) 만들어줘. 위쪽 레일의 번호 원 3개가 차례로 파랗게 켜지며 레일이 왼쪽부터 차오르고(지난 번호는 ✓), 아래 흰 그림 카드 3장이 하나씩 톡 올라오게: ① 휴대폰 QR 코드와 전화 → ② 달력 날짜에 동그라미 → ③ 「예약 확정 ✓」 문자 말풍선. 바탕은 밝은 하늘빛, 지금 단계 카드는 파란 테두리. 제목: 「{title}」. 예약 방법: 「{how}」.[[ 단계 이름: 「{steps}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{title}` 제목 — 예: 진료 예약 방법
- `{how}` 예약 방법 — 예: 전화 02-000-0000 또는 QR 코드
- `{steps}` 단계 이름 (선택) — 예: 전화·QR로 신청 / 날짜 고르기 / 확정 문자 받기
- `{dur}` 지속 시간 (선택) — 예: 6초

## S06 제품 특징 콜아웃 (product spec callouts)

- 이럴 때: 상품 상세 영상, 신제품 소개, 특산물 자랑
- 길이: 4~6초 · 방식: 글자·CSS · 재료: 내 사진·그림 필요
- 용도: 광고, 영업·제안 · 업종: 제조, 쇼핑몰, 농업·특산물

요청 문장:

```
제품 특징 콜아웃(product spec callouts) 만들어줘. 가운데 제품 사진 위 세 곳에 점이 찍히고, 점에서 선이 꺾이며 뻗어 나가 특징 이름표가 하나씩 붙고, 점은 맥박 치듯 깜빡이게. 이미지 파일: {img}. 특징: 「{feats}」.[[ 제품 이름: 「{name}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{img}` 이미지 파일 — 예: product.jpg
- `{feats}` 특징 3가지 — 예: 방수 / 무게 320g / 용량 500ml
- `{name}` 제품 이름 (선택) — 예: ○○ 텀블러
- `{dur}` 지속 시간 (선택) — 예: 5초

## S07 매물 소개 카드 (property listing card)

- 이럴 때: 부동산 매물 영상, 숙소·공간 대여 소개
- 길이: 5~7초 · 방식: 글자·CSS · 재료: 내 사진·그림 필요
- 용도: 영업·제안, 광고 · 업종: 부동산, 숙박, 인테리어·건축

요청 문장:

```
매물 소개 카드(property listing card) 만들어줘. 왼쪽에 매물 사진이 한 장씩 부드럽게 넘어가고, 오른쪽에서 정보 카드가 밀려 들어오며 작은 지도 핀 아이콘이 톡 떨어지게. 매물 이름: 「{title}」. 면적·방·가격: 「{info}」. 위치: 「{place}」.[[ 이미지 파일: {imgs}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{title}` 매물 이름 — 예: ○○동 ○○아파트
- `{info}` 면적·방·가격 — 예: 84㎡ · 방 3 · 욕실 2 · 매매 ○억 원
- `{place}` 위치 — 예: ○○역 도보 7분
- `{imgs}` 사진 파일들 (선택) — 예: room1.jpg, room2.jpg, room3.jpg
- `{dur}` 지속 시간 (선택) — 예: 6초

## S08 평면도 → 3D 집 세우기 (floor plan to 3D)

- 이럴 때: 분양·인테리어 상담, 매물 구조 설명, 숙소 안내
- 길이: 5~7초 · 방식: 3D(Three.js) · 재료: 전부 코드
- 용도: 영업·제안 · 업종: 부동산, 인테리어·건축, 숙박

요청 문장:

```
평면도에서 3D 집 세우기(floor plan to 3D) 만들어줘. 3D는 Three.js로. 위에서 내려다본 바닥에 평면도대로 벽 선을 먼저 그리고, 방마다 바닥 색이 깔린 뒤 벽이 아래에서 쑥 올라오게. 이어서 카메라가 비스듬히 내려와 집을 천천히 돌며 방마다 이름표가 뜨게. 치수를 모르면 방 크기는 평면도 그림을 보고 대략 맞춰줘. 평면도 파일: {plan}. 방 이름: 「{rooms}」.[[ 지속 시간: {dur}.]]
```

칸:

- `{plan}` 평면도 파일 — 예: floorplan.png
- `{rooms}` 방 이름 — 예: 거실 / 주방 / 방1 / 방2 / 욕실
- `{dur}` 지속 시간 (선택) — 예: 6초

## S09 오늘 한정 수량 카운터 (limited stock counter)

- 이럴 때: 한정 판매, 산지 직송 특가, 오늘의 메뉴 마감 안내
- 길이: 4~6초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 광고, 영업·제안 · 업종: 쇼핑몰, 음식점, 농업·특산물

요청 문장:

```
오늘 한정 수량 카운터(limited stock counter) 만들어줘. 상품 이름 아래 큰 숫자가 한 칸씩 굴러 내려가 남은 수량에서 멈추고, 남은 양 막대가 줄어들며 「오늘 남은 수량」 문구가 붙게. 상품: 「{item}」. 남은 수량: 「{left}」.[[ 전체 수량: 「{total}」(숫자는 여기서부터 내려가게).]][[ 지속 시간: {dur}.]]
```

칸:

- `{item}` 상품 — 예: 햇사과 3kg 상자
- `{left}` 남은 수량 — 예: 7개
- `{total}` 전체 수량 (선택) — 예: 20개
- `{dur}` 지속 시간 (선택) — 예: 5초
