# 설명·교육 (7)

강의 설명을 대신하는 도해·채팅·퀴즈.

출처: 모션그래픽 주문 사전 (https://nondev-thinking.web.app/motion/) — 김지백, 한국경영교육연구소 AI ACADEMY «모두의 AI 교실». 2026-11-09 수정본 기준으로 정리.

요청 문장의 `{이름}`은 채울 칸, `[[ … ]]`는 값이 없으면 통째로 빼는 선택 구간이다.

## T10 개념 도해 자동 그리기 (animated diagram · line draw)

- 이럴 때: «자료 → AI → 보고서» 같은 순서 설명
- 길이: 4~6초 · 방식: SVG 선 · 재료: 전부 코드
- 용도: 교육 · 업종: 교육, IT, 공공, 제조

요청 문장:

```
개념 도해 애니메이션(animated diagram) 만들어줘. 단계 상자들이 차례로 튀어나오고 화살표가 선을 그리듯 이어지게. 흰 배경에 남색 글자. 단계: 「{steps}」.[[ 지속 시간: {dur}.]]
```

칸:

- `{steps}` 단계 — 예: 자료 → AI → 보고서
- `{dur}` 지속 시간 (선택) — 예: 5초

## T11 AI 채팅 화면 재현 (chat UI mockup)

- 이럴 때: 프롬프트 강의, AI 사용법 안내
- 길이: 5~10초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육 · 업종: IT, 교육, 유튜버

요청 문장:

```
AI 채팅 화면 재현(chat UI mockup) 만들어줘. 질문이 타자 치듯 입력되고, 점 세 개가 깜박인 뒤 답이 한 줄씩 흘러나오게. 질문: 「{q}」. 답: 「{a}」.[[ 지속 시간: {dur}.]]
```

칸:

- `{q}` 질문 — 예: 회의록 3줄로 요약해줘
- `{a}` AI 답 — 예: ① 예산은 다음 주 확정 / ② 담당은 기획팀 / ③ 교육은 11월 진행
- `{dur}` 지속 시간 (선택) — 예: 7초

## T12 터미널 실행 화면 (terminal typing animation)

- 이럴 때: 코딩·자동화 시연, 설치 방법 안내
- 길이: 4~8초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육 · 업종: IT, 교육

요청 문장:

```
터미널 실행 화면(terminal typing animation) 만들어줘. 검은 창에 명령을 타자로 치고, 진행 줄이 초록 체크와 함께 차례로 뜨게. 명령어: 「{cmd}」. 진행 줄: 「{lines}」.[[ 지속 시간: {dur}.]]
```

칸:

- `{cmd}` 명령어 — 예: npm run build
- `{lines}` 진행 줄 — 예: 파일 읽는 중 / 정리 완료 / 결과 저장
- `{dur}` 지속 시간 (선택) — 예: 6초

## T13 3D 디오라마 — 비유를 입체로 (isometric 3D diorama)

- 이럴 때: 어려운 구조를 비유로 설명할 때
- 길이: 6~12초 · 방식: 3D(Three.js) · 재료: 내 사진·그림 필요
- 용도: 교육 · 업종: 교육, 음식점, 부동산, IT

요청 문장:

```
3D 미니어처 디오라마(isometric diorama) 만들어줘. 3D는 Three.js로. 작은 세트 안에서 빨간 구슬이 자리 사이를 오가고, 자리마다 이름표를 붙여줘. 카메라는 천천히 돌게. 장소: 「{place}」. 이름표: 「{labels}」.[[ 지속 시간: {dur}.]]
```

칸:

- `{place}` 비유할 장소 — 예: 식당
- `{labels}` 자리 이름표 — 예: 손님 = 사용자 / 주문 창구 = API / 주방 = 백엔드
- `{dur}` 지속 시간 (선택) — 예: 8초

## T14 OX 퀴즈 카운트다운 (quiz countdown timer)

- 이럴 때: 강의 중간 참여, 보안·안전 교육, 쇼츠 퀴즈
- 길이: 6~8초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육 · 업종: 교육, 공공, 유튜버, 병원

요청 문장:

```
OX 퀴즈 장면 만들어줘. 문제를 띄우고 원형 타이머가 줄어든 뒤, 큰 정답 도장과 해설 한 줄이 나오게. 문제: 「{q}」. 정답: 「{ans}」. 해설: 「{exp}」.[[ 타이머: {sec}.]]
```

칸:

- `{q}` 문제 — 예: 비밀번호를 AI 채팅창에 넣어도 된다?
- `{ans}` 정답 — 예: X
- `{exp}` 해설 한 줄 — 예: 비밀번호는 절대 넣지 않아요
- `{sec}` 타이머 (선택) — 예: 5초

## T17 용어 팝업 카드 (pop-up info card)

- 이럴 때: 전문 용어가 나오는 순간
- 길이: 3~5초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육 · 업종: 교육, IT, 병원, 공공

요청 문장:

```
용어 팝업 카드(pop-up info card) 만들어줘. 흰 카드가 톡 튀어나와 용어를 크게 보여주고, 아래에 쉬운 뜻을 타자로 친 뒤 형광펜으로 밑줄. 용어: 「{term}」.[[ 영어 풀네임: 「{full}」.]] 쉬운 뜻: 「{mean}」.[[ 넣을 영상: {file}.]][[ 시작 시점: {at}.]]
```

칸:

- `{term}` 용어 — 예: API
- `{full}` 영어 풀네임 (선택) — 예: Application Programming Interface
- `{mean}` 쉬운 뜻 — 예: 식당의 주문 창구
- `{at}` 시작 시점 (선택) — 예: 1:05

## T19 화면 줌 + 스포트라이트 (zoom & spotlight)

- 이럴 때: 사용법 영상, 신청·예약 방법 안내
- 길이: 4~6초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육 · 업종: IT, 교육, 쇼핑몰, 공공

요청 문장:

```
화면 줌과 스포트라이트(zoom & spotlight) 만들어줘. 화면 녹화에서 누를 곳만 밝게 남기고 주변을 어둡게 한 뒤, 그쪽으로 확대하고 안내 말표를 띄워줘. 화면 녹화 파일: {rec}. 누를 곳: 「{target}」. 안내 글자: 「{label}」.[[ 시작 시점: {at}.]]
```

칸:

- `{rec}` 화면 녹화 파일 — 예: screen.mp4
- `{target}` 누를 곳 — 예: 보내기 버튼
- `{label}` 안내 글자 — 예: 여기를 누르세요
- `{at}` 시작 시점 (선택) — 예: 0:40
