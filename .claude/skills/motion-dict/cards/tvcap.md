## F21 인터뷰 자막 (interview subtitle)

- 이럴 때: 수강생 소감, 소리가 작거나 잡음 많은 현장 발언
- 길이: 4~5초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육 · 업종: 교육, 복지·자활, 행사·축제, 유튜버, 공공

요청 문장:

```
인터뷰 자막(interview subtitle) 만들어줘. 화면 아래 가운데에 강조색 작은 이름표가 먼저 뜨고, 바로 아래 발언이 큰따옴표에 감싸인 흰 굵은 글자(어두운 테두리)로 서서히 나타나 말하는 동안 머물게. 색은 영상 배경·옷 색에 맞춰 조정해줘. 화자: 「{who}」. 발언: 「{line}」.[[ 넣을 영상: {file}.]][[ 시작 시점: {at}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{who}` 화자 — 예: 참가자 A
- `{line}` 발언 — 예: 처음엔 어려울 줄 알았는데, 순서만 적으니 되더라고요
- `{at}` 시작 시점 (선택) — 예: 0:05
- `{dur}` 지속 시간 (선택) — 예: 4.5초

## F28 요점 한 줄 띠 (headline strap)

- 이럴 때: 지금 말하는 요점 한 문장을 계속 보이게 할 때
- 길이: 4~5초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육 · 업종: 유튜버, 공공, 병원

요청 문장:

```
요점 한 줄 띠(headline strap) 만들어줘. 화면 왼쪽 아래(말자막 윗줄)에 강조색 머리표 칸이 밀려 들어오고, 그 옆 흰 띠가 왼쪽부터 펼쳐지며 요점 한 문장이 드러나 말하는 동안 머물게. 색은 영상 배경·옷 색에 맞춰 조정해줘. 머리표: 「{tag}」. 요점 문장: 「{text}」.[[ 넣을 영상: {file}.]][[ 시작 시점: {at}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{tag}` 머리표 — 예: 핵심
- `{text}` 요점 문장 — 예: 묻지 말고, 맡기세요 — 확인은 사람이
- `{at}` 시작 시점 (선택) — 예: 0:05
- `{dur}` 지속 시간 (선택) — 예: 4.5초

## F31 단어 강조 자막 (word highlight caption · karaoke)

- 이럴 때: 쇼츠·강의 핵심 문장, 어르신 따라 읽기
- 길이: 4~5초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보, 교육 · 업종: 유튜버, 교육, 복지·자활, 공공

요청 문장:

```
단어 강조 자막(word highlight caption) 만들어줘. 화면 아래 가운데에 흰 굵은 자막(어두운 테두리)이 뜨고, 핵심어를 말하는 순간 그 단어 뒤에 강조색 둥근 칸이 왼쪽부터 한 번 칠해지게. 색은 영상 배경·옷 색에 맞춰 조정해줘. 자막 문장: 「{text}」. 칸 칠할 단어: 「{keyword}」.[[ 단어별 시각: {times}.]][[ 방식: 「{mode}」(따라 읽기면 칸이 말하는 단어를 따라 옮겨 감).]][[ 넣을 영상: {file}.]][[ 시작 시점: {at}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{text}` 자막 문장 — 예: 묻지 말고, 맡기세요
- `{keyword}` 칸 칠할 단어 — 예: 맡기세요
- `{times}` 단어별 시각(자막 시작부터) (선택) — 예: 묻지 0초 / 말고 0.4초 / 맡기세요 0.9초
- `{mode}` 방식 (선택) — 예: 따라 읽기
- `{at}` 시작 시점 (선택) — 예: 0:05
- `{dur}` 지속 시간 (선택) — 예: 4.5초

## F32 소리 자막 (sound effect caption)

- 이럴 때: 현장 강의 박수·웃음, 알림음, 배경음악 곡 정보
- 길이: 3~5초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육 · 업종: 교육, 유튜버, 행사·축제, 공공

요청 문장:

```
소리 자막(sound effect caption) 만들어줘. 화면 아래 가운데(말자막 윗줄)에 밝은 반투명 알약이 톡 뜨고, 안에 단색 소리 기호와 대괄호 글을 넣어 기호가 한 번 두근거리게. 기호는 글에 맞게(손뼉·웃는 얼굴·종·키보드·스피커·음표). 색은 영상 배경·옷 색에 맞춰 조정해줘. 소리 글: 「{text}」.[[ 소리 기호: 「{icon}」.]][[ 왼쪽 아래 곡 정보 줄: 「{music}」.]][[ 넣을 영상: {file}.]][[ 시작 시점: {at}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{text}` 소리 글 — 예: [수강생들 웃음]
- `{icon}` 소리 기호 (선택) — 예: 웃는 얼굴
- `{music}` 곡 정보 줄 (선택) — 예: 잔잔한 피아노 · 무료 음원
- `{at}` 시작 시점 (선택) — 예: 0:05
- `{dur}` 지속 시간 (선택) — 예: 4초

## F33 기대 → 현실 반전 자막 (expectation vs reality caption)

- 이럴 때: «AI가 다 해 준다» 같은 오해 바로잡기, 실패담
- 길이: 4~5초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육 · 업종: 유튜버, IT, 운동·헬스

요청 문장:

```
기대 → 현실 반전 자막(expectation vs reality caption) 만들어줘. 화면 아래쪽에 기대 문장이 먼저 뜨고, 잠시 뒤 강조색 취소선이 그어지며 흐려진 다음, 그 아래 살짝 기운 강조색 판에 현실 문장이 «탁» 찍히게. 색은 영상 배경·옷 색에 맞춰 조정해줘. 앞 칩: 「{tag1}」. 기대 문장: 「{expect}」. 뒤 칩: 「{tag2}」. 현실 문장: 「{reality}」.[[ 넣을 영상: {file}.]][[ 시작 시점: {at}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{tag1}` 앞 칩 — 예: 기대
- `{expect}` 기대 문장 — 예: AI가 알아서 다 해 준다
- `{tag2}` 뒤 칩 — 예: 현실
- `{reality}` 현실 문장 — 예: 잘 물어봐야 해 준다
- `{at}` 시작 시점 (선택) — 예: 0:05
- `{dur}` 지속 시간 (선택) — 예: 4.5초

## F34 정지 화면 해설 (freeze frame callout)

- 이럴 때: 실수하기 쉬운 순간, 현장 반응을 멈춰 풀이
- 길이: 4~6초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육 · 업종: 유튜버, IT, 운동·헬스

요청 문장:

```
정지 화면 해설(freeze frame callout) 만들어줘. 영상이 한 장면에서 멈춘 듯 색이 빠지고 가장자리가 어두워진 뒤, 왼쪽 위에 「❚❚ 잠깐」 칩이 뜨고 얼굴 반대쪽에서 흰 해설 카드가 밀려 들어오게. 색은 영상 배경·옷 색에 맞춰 조정해줘. 머리말: 「{kicker}」. 해설: 「{text}」.[[ 가리킬 곳: 「{mark}」 — 강조색 동그라미와 카드에서 잇는 선으로.]][[ 넣을 영상: {file}.]][[ 멈출 시점: {at}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{kicker}` 머리말 — 예: 잠깐!
- `{text}` 해설 — 예: 작은 핀 마이크 하나로 소리가 확 달라집니다
- `{mark}` 가리킬 곳 (선택) — 예: 가슴의 핀 마이크
- `{at}` 멈출 시점 (선택) — 예: 0:12
- `{dur}` 지속 시간 (선택) — 예: 5초

## F36 빨리감기 표시 + 실제 걸린 시간 (fast-forward indicator)

- 이럴 때: AI 답 기다리기·설치·요리 과정 빨리 감기
- 길이: 4~6초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육 · 업종: IT, 유튜버, 음식점, 제조

요청 문장:

```
빨리감기 표시 + 실제 걸린 시간(fast-forward indicator) 만들어줘. 빨리 감은 구간 동안 화면 오른쪽 위에 ▶▶ 배속 배지와 실제 시간 판이 톡 뜨고, 숫자가 실제 걸린 시간까지 한 번 올라가며 진행선이 차오른 뒤 «완료 ✓» 칩이 붙게. 색은 영상 배경·옷 색에 맞춰 조정해줘. 완료 칩 초록은 그대로. 배속: 「{speed}」. 실제 걸린 시간: 「{real}」.[[ 넣을 영상: {file}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{speed}` 배속 — 예: ×8
- `{real}` 실제 걸린 시간 — 예: 2분 40초
- `{dur}` 지속 시간 (선택) — 예: 5초

요청 문장:

```
잠시 후 예고(coming up tease) 만들어줘. 오른쪽 아래로 작은 판이 밀려 들어와 «잠시 후» 칩·남은 시간·예고 문장과, 그 장면 한 컷을 살짝 흐리게 넣은 미리보기 창을 보여 주게. 예고는 실제로 나오는 장면만. 색은 영상 배경·옷 색에 맞춰 조정해줘. 예고 문장: 「{text}」. 남은 시간: 「{when}」. 그 장면 시각: 「{at}」.[[ 넣을 영상: {file}.]][[ 지속 시간: {dur}.]]
```

- `{dur}` 지속 시간 (선택) — 예: 4.5초

## F38 편집자 주 (editor's note)

- 길이: 4~6초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육 · 업종: 유튜버, IT, 금융·보험, 공공

요청 문장:

```
편집자 주(editor's note) 만들어줘. 화면 위쪽 가운데로 흰 메모 판이 내려오고, 왼쪽 강조색 칸의 연필 아래 밑줄이 쓱 그어진 뒤 본문·«확인한 날 · 출처»가 차례로 뜨게. 색은 영상 배경·옷 색에 맞춰 조정해줘. 머리말: 「편집자 주 · {kind}」. 본문: 「{text}」. 확인한 날: 「{date}」. 출처: 「{source}」.[[ 정정 전 말(회색 취소선 → 본문): 「{said}」.]][[ 넣을 영상: {file}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{kind}` 종류(정정·보충·업데이트) — 예: 업데이트
- `{text}` 본문 — 예: 요금은 바뀔 수 있어요 — 공식 페이지에서 다시 확인해 주세요
- `{date}` 확인한 날 — 예: 2026.10.4
- `{source}` 출처 — 예: ○○ 공식 요금 안내
- `{said}` 정정 전 말 (선택) — 예: 월 ○만 원
- `{dur}` 지속 시간 (선택) — 예: 5초

## F39 말 번역 자막 (plain-language caption)

- 이럴 때: 어려운 말을 쉬운 말로 — 어르신·처음 배우는 분
- 길이: 4~5초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육 · 업종: IT, 병원, 공공, 복지·자활

요청 문장:

```
말 번역 자막(plain-language caption) 만들어줘. 화면 아래 자막 자리에 작은 회색 «원래 말» 줄 → ↓ → 크고 굵은 흰 «쉬운 말» 줄이 왼쪽부터 드러나고, 바뀐 핵심어 아래에 강조색 밑줄이 그어지게. 색은 영상 배경·옷 색에 맞춰 조정해줘. 원래 말: 「{said}」. 쉬운 말: 「{plain}」. 밑줄 칠 말: 「{key}」.[[ 넣을 영상: {file}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{said}` 원래 말 — 예: API 키를 발급받으세요

- `{key}` 밑줄 칠 말 — 예: 출입증 번호
- `{dur}` 지속 시간 (선택) — 예: 4.5초
