## F01 사진 크게 + 아래 설명 띠 (photo caption bar)

- 이럴 때: 현장 사진·AI 결과물을 한두 줄로 설명할 때
- 길이: 4~5초 · 방식: 글자·CSS · 재료: 내 사진·그림 필요
- 용도: 교육 · 업종: 제조, 관광·지역, 복지·자활, 유튜버

요청 문장:

```
사진 크게 + 아래 설명 띠(photo caption bar) 만들어줘. 사진이 화면을 꽉 채운 채 아주 천천히 커지고, 아래 4분의 1을 덮는 반투명 띠가 올라와 제목·설명이 차례로 뜨게. 색은 영상 배경·옷 색에 맞춰 조정해줘. 이미지 파일: {img}. 제목: 「{title}」. 설명: 「{body}」.[[ 출처: 「{source}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{img}` 이미지 파일 — 예: photo.jpg
- `{title}` 제목 — 예: 포장 작업장
- `{body}` 설명 — 예: 주문이 몰리는 오전, 손으로 하던 포장 순서를 AI가 정리해 줍니다
- `{source}` 출처 (선택) — 예: 이미지: AI 생성
- `{dur}` 지속 시간 (선택) — 예: 4.5초

## F02 왼쪽 사진 · 오른쪽 설명 (photo and bullet points)

- 이럴 때: 도구·사례를 처음 소개할 때 — 사진 한 장 + 핵심 3줄
- 길이: 4~5초 · 방식: 글자·CSS · 재료: 내 사진·그림 필요
- 용도: 교육 · 업종: 음식점, 쇼핑몰, IT

요청 문장:

```
왼쪽 사진 · 오른쪽 설명(photo and bullet points) 만들어줘. 밝은 종이 바탕 왼쪽에 큰 사진이 밀려 들어오고, 오른쪽에 머리말·제목·번호 붙은 설명 3줄이 차례로 올라오게. 색은 영상 배경·옷 색에 맞춰 조정해줘. 이미지 파일: {img}. 머리말: 「{kicker}」. 제목: 「{title}」. 설명(/로 나눔): 「{items}」.[[ 출처: 「{source}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{img}` 이미지 파일 — 예: photo.jpg
- `{kicker}` 머리말 — 예: 사례
- `{title}` 제목 — 예: 메뉴판 정리
- `{items}` 설명 3줄 — 예: 메뉴 사진을 찍으면 / AI가 이름·가격을 표로 / 손님 안내문까지 한 번에
- `{source}` 출처 (선택) — 예: 이미지: AI 생성
- `{dur}` 지속 시간 (선택) — 예: 4.5초

## F03 전·후 사진 2장 비교 (side-by-side comparison)

- 이럴 때: AI 쓰기 전·후 결과물, 정리 전·후, 공사·시술 전·후
- 길이: 4~5초 · 방식: 글자·CSS · 재료: 내 사진·그림 필요
- 용도: 영업·제안, 광고, 교육 · 업종: 인테리어·건축, 뷰티, 제조

요청 문장:

```
전·후 사진 2장 비교(side-by-side comparison) 만들어줘. 어두운 판 위에 이전 사진(색 조금 뺌)은 왼쪽에서, 이후 사진은 오른쪽에서 들어와 나란히 서고, 꼬리표·세로줄·한 줄 정리가 차례로 뜨게. 색은 영상 배경·옷 색에 맞춰 조정해줘. 사진 파일(이전, 이후): {imgs}. 이전 꼬리표: 「{l1}」. 이후 꼬리표: 「{l2}」. 한 줄 정리: 「{caption}」.[[ 지속 시간: {dur}.]]
```

칸:

- `{imgs}` 사진 파일(이전, 이후) — 예: before.jpg, after.jpg
- `{l1}` 이전 꼬리표 — 예: 이전 · 손으로 하나씩 포장
- `{l2}` 이후 꼬리표 — 예: 이후 · 순서대로 묶음 출고
- `{caption}` 한 줄 정리 — 예: 같은 일, 순서만 바꿨습니다
- `{dur}` 지속 시간 (선택) — 예: 4.5초

```

요청 문장:

```
그림 용어 카드(definition card) 만들어줘. 얼굴을 가리지 않게 화면 오른쪽 위에 그림 붙은 흰 카드가 아래에서 올라오고, 용어 아래 뜻에 형광펜이 칠해진 뒤 쉬운 비유가 뜨게. 색은 영상 배경·옷 색에 맞춰 조정해줘. 용어: 「{term}」. 뜻: 「{mean}」. 쉬운 비유: 「{like}」. 그림 파일: {img}.[[ 넣을 영상: {file}.]][[ 시작 시점: {at}.]][[ 지속 시간: {dur}.]]
