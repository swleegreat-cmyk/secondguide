# 엔딩·구독 (4)

시청을 행동으로 잇는 마무리.

출처: 모션그래픽 주문 사전 (https://nondev-thinking.web.app/motion/) — 김지백, 한국경영교육연구소 AI ACADEMY «모두의 AI 교실». 2026-11-09 수정본 기준으로 정리.

요청 문장의 `{이름}`은 채울 칸, `[[ … ]]`는 값이 없으면 통째로 빼는 선택 구간이다.

## T05 전화 CTA 엔드카드 (CTA end card)

- 이럴 때: 예약·문의 유도 영상 끝
- 길이: 3~5초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 광고, 영업·제안 · 업종: 병원, 부동산, 음식점

요청 문장:

```
전화 CTA 엔드카드(CTA end card) 만들어줘. 제목 아래 전화번호를 타자 치듯 띄우고, 버튼이 두근거리게. 제목: 「{title}」. 전화번호: 「{phone}」.[[ 버튼 글자: 「{btn}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{title}` 제목 — 예: 예약 문의
- `{phone}` 전화번호 — 예: 02-000-0000
- `{btn}` 버튼 글자 (선택) — 예: 지금 전화하기
- `{dur}` 지속 시간 (선택) — 예: 5초

## B17 챕터 진행 바 (chapter progress bar)

- 이럴 때: 10분 넘는 강의·설명 영상
- 길이: 영상 내내 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육 · 업종: 교육, 유튜버, IT

요청 문장:

```
챕터 진행 바(chapter progress bar) 만들어줘. 화면 위에 단원 점들이 있고, 영상 시간에 맞춰 지금 단원에 불이 옮겨 가게. 단원: 「{chapters}」.[[ 단원 시작 시각: {times}.]][[ 넣을 영상: {file}.]]
```

칸:

- `{chapters}` 단원 — 예: 도입 / 개념 / 실습 / 주의 / 정리
- `{times}` 단원 시작 시각 (선택) — 예: 0:00 / 2:10 / 5:00 / 8:30 / 10:00

## B18 구독·좋아요 유도 (subscribe button animation)

- 이럴 때: 영상 초반·후반 구독 유도
- 길이: 3~4초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보 · 업종: 유튜버, 음식점, 쇼핑몰

요청 문장:

```
구독·좋아요 유도 애니메이션(subscribe button animation) 만들어줘. 화면 아래 가운데에 좋아요(👍) · 빨간 「구독」 버튼 · 종(🔔)이 든 둥근 판이 뜨면, 마우스 커서가 오른쪽 아래에서 1초쯤 걸려 들어와 「구독」 버튼을 누르고 버튼이 회색 「구독중」으로 바뀌게. 누르고 0.4초쯤 뒤 종이 흔들리다 잦아들고, 종이 멈출 즈음 좋아요가 톡 튀게.[[ 넣을 영상: {file}.]][[ 시작 시점: {at}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{at}` 시작 시점 (선택) — 예: 0:30
- `{dur}` 지속 시간 (선택) — 예: 4초

## B20 엔딩 카드 (end screen)

- 이럴 때: 유튜브 최종 화면(엔드스크린)
- 길이: 5~20초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보 · 업종: 유튜버, 쇼핑몰

요청 문장:

```
유튜브 엔딩 카드(end screen) 만들어줘. 배경은 흐리게, 인사 문구 아래에 다음 영상 칸 2개와 구독 동그라미 자리를 비워 둬. 인사 문구: 「{msg}」.[[ 넣을 영상: {file}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{msg}` 인사 문구 — 예: 시청해 주셔서 감사합니다
- `{dur}` 지속 시간 (선택) — 예: 20초
