# 오프닝·로고 (4)

로고 인트로·타이틀·배경.

출처: 모션그래픽 주문 사전 (https://nondev-thinking.web.app/motion/) — 김지백, 한국경영교육연구소 AI ACADEMY «모두의 AI 교실». 2026-11-09 수정본 기준으로 정리.

요청 문장의 `{이름}`은 채울 칸, `[[ … ]]`는 값이 없으면 통째로 빼는 선택 구간이다.

## T01 입자 로고 인트로 (particle logo reveal)

- 이럴 때: 홍보영상·채널 인트로
- 길이: 3~5초 · 방식: 3D(Three.js)+물리 · 재료: 전부 코드
- 용도: 홍보 · 업종: 쇼핑몰, IT, 뷰티, 유튜버

요청 문장:

```
입자 로고 인트로(particle logo reveal) 만들어줘. 3D는 Three.js로. 흩어진 빛 알갱이 수천 개가 모여 로고 모양이 되고, 잠시 반짝인 뒤 흩어지게. 로고 파일: {logo}.[[ 지속 시간: {dur}.]]
```

칸:

- `{logo}` 로고 파일 — 예: logo.png
- `{dur}` 지속 시간 (선택) — 예: 5초

## B08 3D 로고 스팅 (3D logo sting)

- 이럴 때: 매 영상 맨 앞 1번
- 길이: 1.5~2.5초 · 방식: 3D(Three.js) · 재료: 전부 코드
- 용도: 홍보 · 업종: 유튜버, IT, 제조, 공공

요청 문장:

```
3D 로고 스팅(logo sting) 만들어줘. 3D는 Three.js로. 금속 테두리 동전 모양 배지에 로고를 새겨, 빙글 돌다 멈추고 표면에 빛이 한 번 쓱 지나가게. 로고 파일: {logo}.[[ 지속 시간: {dur}.]]
```

칸:

- `{logo}` 로고 파일 — 예: logo.png
- `{dur}` 지속 시간 (선택) — 예: 2초

## B19 3D 무대 오프닝 타이틀 (3D stage opening title)

- 이럴 때: 시즌 첫 화, 특집·행사 오프닝
- 길이: 3~5초 · 방식: 3D(Three.js) · 재료: 전부 코드
- 용도: 홍보 · 업종: 유튜버, 공공, 제조

요청 문장:

```
3D 무대 오프닝 타이틀(3D stage opening title) 만들어줘. 3D는 Three.js로. 캄캄한 무대 위쪽에 따뜻한 흰색 조명 4개가 왼쪽부터 하나씩 탁 깜빡이며 켜져 바닥까지 빛기둥을 드리우고, 무대 뒤에 빨간 빛이 은은히 번지면 가운데로 제목이 아래에서 떠오르게. 제목: 「{title}」.[[ 작은 글자(제목 위): 「{sub}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{title}` 제목 — 예: 모두의 AI교육
- `{sub}` 작은 글자 (선택) — 예: 시즌 2 · 1화
- `{dur}` 지속 시간 (선택) — 예: 5초

## T15 물결 배경 루프 (animated gradient background loop)

- 이럴 때: 챕터 표지, 쇼츠 배경, 자막 뒤 배경
- 길이: 무한 반복 · 방식: 3D(Three.js)+셰이더 · 재료: 전부 코드
- 용도: 홍보 · 업종: 유튜버, IT, 뷰티

요청 문장:

```
끊김 없이 반복되는 배경 영상(background loop) 만들어줘. 그라데이션이 물결처럼 흐르고 작은 점무늬가 물결 따라 반짝이게. 마지막 장면이 첫 장면과 똑같이 이어져서 반복해도 이어 붙인 자리가 안 보이게. 배경 색: {colors}.[[ 가운데 글자: 「{text}」.]][[ 반복 길이: {dur}.]]
```

칸:

- `{text}` 가운데 글자 (선택) — 예: CHAPTER 03
- `{colors}` 배경 색 — 예: 남색과 파랑, 물결 꼭대기에 주황빛
- `{dur}` 반복 길이 (선택) — 예: 8초
