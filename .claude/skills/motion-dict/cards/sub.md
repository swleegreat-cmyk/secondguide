# 자막·글자 (6)

말을 글자로 살리는 장면.

출처: 모션그래픽 주문 사전 (https://nondev-thinking.web.app/motion/) — 김지백, 한국경영교육연구소 AI ACADEMY «모두의 AI 교실». 2026-11-09 수정본 기준으로 정리.

요청 문장의 `{이름}`은 채울 칸, `[[ … ]]`는 값이 없으면 통째로 빼는 선택 구간이다.

## T03 키네틱 타이포 — 쇼츠 3초 훅 (kinetic typography)

- 이럴 때: 쇼츠·릴스 오프닝, 광고 첫 화면
- 길이: 2~3초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 광고, 홍보 · 업종: 유튜버, 쇼핑몰, 음식점, 뷰티

요청 문장:

```
키네틱 타이포(kinetic typography) 장면 만들어줘. 단어가 하나씩 크게 쾅 박히고 살짝 흔들리게, 단어마다 배경색을 바꿔줘. 단어: 「{words}」.[[ 길이: {dur}.]]
```

칸:

- `{words}` 단어들 — 예: 이거 / 모르면 / 손해
- `{dur}` 길이 (선택) — 예: 3초

## B01 예능 효과 자막 (variety show caption · pop text)

- 이럴 때: 놀람·웃음 포인트, 리액션 강조
- 길이: 1~1.5초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보, 교육 · 업종: 유튜버, 음식점, 뷰티

요청 문장:

```
예능 효과 자막(variety show caption) 만들어줘. 노란 글자에 굵은 검정 외곽선으로 뿅 튀어나와 흔들리다 사라지게. 얼굴은 가리지 말아줘. 글자: 「{text}」.[[ 왼쪽 위에는 흰 바탕·굵은 테두리 상자로 상황 설명도 띄워줘: 「{situ}」.]][[ 넣을 영상: {file}.]][[ 시작 시점: {at}.]][[ 지속 시간: {dur}.]][[ 위치: {pos}.]]
```

칸:

- `{text}` 넣을 글자 — 예: 헉!
- `{at}` 시작 시점 (선택) — 예: 0:05
- `{dur}` 지속 시간 (선택) — 예: 1.5초
- `{pos}` 위치 (선택) — 예: 오른쪽 위
- `{situ}` 상황 설명 상자 (선택) — 예: 상황: 처음 써 보는 자동 분류

## B02 속마음 자막 (inner-thought caption)

- 이럴 때: 공감 포인트, 머뭇거리는 순간
- 길이: 1.5~3초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보, 교육 · 업종: 유튜버, 음식점

요청 문장:

```
속마음 자막(inner-thought caption) 만들어줘. 문장이 한 글자씩 흐릿하게 번지며 떠오르고, 그동안 배경 영상의 색을 살짝 빼줘. 문장: 「{text}」.[[ 넣을 영상: {file}.]][[ 시작 시점: {at}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{text}` 속마음 문장 — 예: (나만 모르나…)
- `{at}` 시작 시점 (선택) — 예: 0:12
- `{dur}` 지속 시간 (선택) — 예: 2.5초

## B03 효과 도장 (stamp impact)

- 이럴 때: 정답 공개, 결론 한 줄 못 박기
- 길이: 0.6~1초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보, 교육 · 업종: 유튜버, 쇼핑몰

요청 문장:

```
효과 도장(stamp impact) 만들어줘. 빨간 원형 도장이 크게 떨어지며 쾅 찍히고, 잉크 방울이 튀고 화면이 0.3초 흔들리게. 도장 글자: 「{text}」.[[ 넣을 영상: {file}.]][[ 시작 시점: {at}.]]
```

칸:

- `{text}` 도장 글자 — 예: 정답
- `{at}` 시작 시점 (선택) — 예: 0:20

## B07 뉴스 속보 띠 + 흐르는 자막 (breaking news bar · ticker)

- 이럴 때: 핵심 한 줄 강조, 공지·일정 안내
- 길이: 5~20초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보, 교육 · 업종: 공공, 유튜버, 부동산

요청 문장:

```
뉴스 속보 띠(breaking news bar)와 흐르는 자막(ticker) 만들어줘. 빨간 「속보」 딱지와 제목 띠가 들어오고, 맨 아래로 문장들이 계속 흐르게. 제목: 「{title}」. 흐르는 문장: 「{ticker}」.[[ 넣을 영상: {file}.]][[ 시작 시점: {at}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{title}` 제목 — 예: 오늘의 핵심: 질문을 바꾸면 답이 바뀐다
- `{ticker}` 흐르는 문장 — 예: 다음 시간 안내 / 자료는 고정 댓글에 / 질문은 댓글로
- `{at}` 시작 시점 (선택) — 예: 0:30
- `{dur}` 지속 시간 (선택) — 예: 15초

## T20 인용문 카드 + 필름 그레인 (quote card · film grain)

- 이럴 때: 강의 마무리 한 문장, 법·정책 문구 소개
- 길이: 5~8초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보, 교육 · 업종: 교육, 공공, 유튜버, 뷰티

요청 문장:

```
인용문 카드(quote card) 만들어줘. 인용문이 한 단어씩 떠오르고, 옛날 필름 같은 입자(film grain)와 어두운 가장자리(vignette)를 얹어줘. 마지막에 출처를 작게. 인용문: 「{quote}」. 출처: 「{src}」.[[ 지속 시간: {dur}.]]
```

칸:

- `{quote}` 인용문 — 예: 좋은 질문이 좋은 답을 만든다
- `{src}` 출처 — 예: 출처 이름
- `{dur}` 지속 시간 (선택) — 예: 6초
