# 일정·행사 (7)

날짜·시간표·연혁·참가 신청.

출처: 모션그래픽 주문 사전 (https://nondev-thinking.web.app/motion/) — 김지백, 한국경영교육연구소 AI ACADEMY «모두의 AI 교실». 2026-11-09 수정본 기준으로 정리.

요청 문장의 `{이름}`은 채울 칸, `[[ … ]]`는 값이 없으면 통째로 빼는 선택 구간이다.

## E01 D-day 카운트다운 (event countdown)

- 이럴 때: 행사·개강·개업 날짜 알리기, 예고 쇼츠
- 길이: 4~6초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보 · 업종: 행사·축제, 교육, 쇼핑몰, 공공

요청 문장:

```
D-day 카운트다운(event countdown) 만들어줘. 넘기는 숫자판(플립 시계처럼)이 D-7, D-3, D-1로 착착 넘어가다 마지막에 D-DAY로 바뀌며 축하 효과가 터지고, 아래에 행사 이름과 날짜가 붙게. 행사 이름: 「{name}」. 날짜: 「{date}」.[[ 장소: 「{place}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{name}` 행사 이름 — 예: ○○시 가을 축제
- `{date}` 날짜 — 예: 10월 3일(토)
- `{place}` 장소 (선택) — 예: ○○체육관
- `{dur}` 지속 시간 (선택) — 예: 5초

## E02 행사 시간표 (event timetable)

- 이럴 때: 행사장 대기 화면, 교육·세미나 순서 안내
- 길이: 5~8초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보, 교육 · 업종: 행사·축제, 교육, 공공, 복지·자활

요청 문장:

```
행사 시간표(event timetable) 만들어줘. 시간과 순서가 한 줄씩 켜지고, 「지금」 막대가 진행 중인 줄로 미끄러져 옮겨 가며 끝난 줄은 흐려지게. 행사 이름: 「{title}」. 시간표: 「{rows}」.[[ 진행 중인 순서: 「{now}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{title}` 행사 이름 — 예: ○○센터 가을 행사
- `{rows}` 시간표 — 예: 10:00 등록 / 10:30 개회식 / 11:00 특강 / 12:00 점심
- `{now}` 진행 중인 순서 (선택) — 예: 11:00 특강
- `{dur}` 지속 시간 (선택) — 예: 6초

## E03 연혁 타임라인 (history timeline)

- 이럴 때: 기관·회사 소개 영상, 개소 ○주년 기념
- 길이: 6~10초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 영업·제안, 홍보 · 업종: 제조, 공공, 복지·자활

요청 문장:

```
연혁 타임라인(history timeline) 만들어줘. 가로선이 왼쪽에서 오른쪽으로 그려지며 연도 점이 차례로 톡 뜨고, 점마다 작은 사진 카드와 한 줄 기록이 붙게. 연도와 기록: 「{hist}」.[[ 이미지 파일: {imgs}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{hist}` 연도와 기록 — 예: 2010 ○○센터 개소 / 2016 제2사업장 / 2020 우수기관 선정 / 2024 이용자 1만 명
- `{imgs}` 사진 파일들 (선택) — 예: photo1.jpg, photo2.jpg, photo3.jpg, photo4.jpg
- `{dur}` 지속 시간 (선택) — 예: 8초

## E04 행사 포스터 모션 (animated event poster)

- 이럴 때: 행사 홍보 쇼츠, 카카오톡·SNS 공유용 포스터
- 길이: 5~8초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보 · 업종: 행사·축제, 공공, 복지·자활

요청 문장:

```
행사 포스터 모션(animated event poster) 만들어줘. 세로 포스터 판 위에 색 도형이 먼저 깔리고, 큰 제목·날짜 블록·장소·문의가 차례로 조립되듯 들어오게. 제목: 「{title}」. 날짜: 「{date}」. 장소: 「{place}」.[[ 문의: 「{contact}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{title}` 제목 — 예: 가을 나눔 장터
- `{date}` 날짜 — 예: 10월 17일(토) 10:00~16:00
- `{place}` 장소 — 예: ○○시청 광장
- `{contact}` 문의 (선택) — 예: 02-000-0000
- `{dur}` 지속 시간 (선택) — 예: 6초

## E05 QR로 참가 신청 (scan-QR call to action)

- 이럴 때: 행사·교육 참가 신청, 설문 참여 안내
- 길이: 4~6초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보 · 업종: 행사·축제, 공공, 교육, 복지·자활

요청 문장:

```
QR 참가 신청 화면(scan-QR call to action) 만들어줘. QR 코드 둘레를 스캔 빛이 돌고 모서리 괄호가 조여 오며, 옆에 안내 문구가 뜨게[[ — 그 아래 마감일 칩도 붙여줘(마감일: 「{due}」)]]. QR 코드는 뒤에 적은 신청 페이지 주소로 실제로 찍히게 해줘. 신청 페이지 주소: {url}.[[ 안내 문구: 「{msg}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{url}` 신청 페이지 주소 — 예: https://example.com/apply
- `{due}` 마감일 (선택) — 예: 10월 10일
- `{msg}` 안내 문구 (선택) — 예: 휴대폰 카메라로 찍으세요
- `{dur}` 지속 시간 (선택) — 예: 5초

## E06 축제 불꽃 오프닝 (festival fireworks opening)

- 이럴 때: 축제·행사 영상 첫 장면, 개막 알림
- 길이: 4~6초 · 방식: 3D(Three.js) · 재료: 전부 코드
- 용도: 홍보 · 업종: 행사·축제, 관광·지역, 공공

요청 문장:

```
축제 불꽃 오프닝(festival fireworks opening) 만들어줘. 3D는 Three.js로. 밤하늘에 입자 불꽃이 세 번 솟아 터져 중력을 받아 흩어지며 떨어지고, 가운데로 축제 이름이 빛나며 떠오른 뒤 그 아래 날짜가 붙게. 축제 이름: 「{name}」. 날짜: 「{date}」. 불꽃 색(터지는 차례대로): {fire}.[[ 지속 시간: {dur}.]]
```

칸:

- `{name}` 축제 이름 — 예: ○○시 빛 축제
- `{date}` 날짜 — 예: 10월 3일 ~ 5일
- `{fire}` 불꽃 색 — 예: 금빛 주황 · 분홍 · 하늘색
- `{dur}` 지속 시간 (선택) — 예: 5초

## E07 행사장 부스 배치도 (venue booth map)

- 이럴 때: 박람회·장터·채용 행사 안내, 행사장 대기 화면
- 길이: 5~8초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보 · 업종: 행사·축제, 공공, 복지·자활

요청 문장:

```
행사장 부스 배치도(venue booth map) 만들어줘. 위에서 내려다본 행사장 격자에 부스가 하나씩 켜지고, 입구에서 안내할 부스까지 점선 길이 그려진 뒤 핀이 꽂히며 부스 이름 말풍선이 붙게. 부스 목록: 「{booths}」. 안내할 부스: 「{target}」.[[ 행사장 도면 파일: {plan}. 부스 위치는 이 도면을 따라줘.]][[ 지속 시간: {dur}.]]
```

칸:

- `{booths}` 부스 목록 — 예: 먹거리 2곳 / 체험 2곳 / 상담 / 판매 3곳 / 홍보 / 쉼터
- `{target}` 안내할 부스 — 예: 상담 부스
- `{plan}` 행사장 도면 파일 (선택) — 예: floor.png
- `{dur}` 지속 시간 (선택) — 예: 6초
