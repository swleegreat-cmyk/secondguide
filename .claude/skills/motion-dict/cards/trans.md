# 장면 전환 (6)

장면과 장면 사이를 잇는 기술.

출처: 모션그래픽 주문 사전 (https://nondev-thinking.web.app/motion/) — 김지백, 한국경영교육연구소 AI ACADEMY «모두의 AI 교실». 2026-11-09 수정본 기준으로 정리.

요청 문장의 `{이름}`은 채울 칸, `[[ … ]]`는 값이 없으면 통째로 빼는 선택 구간이다.

## B09 코너 전환 브리지 (bumper · title bridge)

- 이럴 때: 코너·챕터가 바뀔 때
- 길이: 1~1.5초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보, 교육 · 업종: 유튜버, 공공

요청 문장:

```
코너 전환 브리지(bumper) 만들어줘. 빨강·검정 면이 사선으로 휙 지나가며 큰 번호와 제목이 1.5초 보였다 사라지게. 번호: 「{num}」. 제목: 「{title}」.[[ 넣을 영상: {file}.]][[ 시작 시점: {at}.]]
```

칸:

- `{num}` 번호 — 예: 02
- `{title}` 제목 — 예: 실습 시간
- `{at}` 시작 시점 (선택) — 예: 3:00

## B12 3D 큐브 전환 (cube transition)

- 이럴 때: 주제가 확 바뀔 때
- 길이: 0.8~1.2초 · 방식: 3D(Three.js) · 재료: 전부 코드
- 용도: 홍보, 교육 · 업종: 유튜버, IT, 쇼핑몰

요청 문장:

```
3D 큐브 전환(cube transition) 만들어줘. 3D는 Three.js로. 앞 장면이 주사위 옆면처럼 돌아가며 다음 장면이 나오게. 앞 장면: {a}. 다음 장면: {b}.[[ 전환 시점: {at}.]][[ 전환 길이: {dur}.]]
```

칸:

- `{a}` 앞 장면 — 예: a.mp4
- `{b}` 다음 장면 — 예: b.mp4
- `{at}` 전환 시점 (선택) — 예: 1:20
- `{dur}` 전환 길이 (선택) — 예: 1초

## B13 잉크 번짐 전환 (ink bleed transition)

- 이럴 때: 감성 장면, 챕터 전환, 붓글씨 제목이 먹처럼 번지며 나타날 때
- 길이: 1~1.5초 · 방식: 3D(Three.js)+셰이더 · 재료: 전부 코드
- 용도: 홍보, 교육 · 업종: 뷰티, 공공, 음식점

요청 문장:

```
잉크 번짐 전환(ink bleed transition) 만들어줘. 먹물이 번지듯 가장자리가 울퉁불퉁하게 퍼지며 앞 장면에서 다음 장면으로 바뀌게. 셰이더로. 앞 장면: {a}. 다음 장면: {b}.[[ 전환 시점: {at}.]][[ 전환 길이: {dur}.]]
```

칸:

- `{a}` 앞 장면 — 예: a.mp4
- `{b}` 다음 장면 — 예: b.mp4
- `{at}` 전환 시점 (선택) — 예: 2:05
- `{dur}` 전환 길이 (선택) — 예: 1.5초

## B14 필름 빛 샘 전환 (light leak transition)

- 이럴 때: 브이로그, 감성 장면
- 길이: 0.6~1초 · 방식: 셰이더 · 재료: 전부 코드
- 용도: 홍보, 교육 · 업종: 뷰티, 음식점, 유튜버

요청 문장:

```
필름 빛 샘 전환(light leak transition) 만들어줘. 필름에 빛이 새어 들어오듯 화면 왼쪽 위에서 큰 빛 덩어리가 번져 들어와 오른쪽 아래로 비스듬히 가로지르고, 빛이 가장 밝아 화면이 하얗게 뜨는 순간 앞 장면에서 다음 장면으로 바뀐 뒤 빛이 옅어지며 빠져나가게. 빛 색: {tone}(한가운데는 따뜻한 흰색). 앞 장면: {a}. 다음 장면: {b}.[[ 넣을 영상: {file}.]][[ 전환 시점: {at}.]][[ 전환 길이: {dur}.]]
```

칸:

- `{a}` 앞 장면 — 예: a.mp4
- `{b}` 다음 장면 — 예: b.mp4
- `{tone}` 빛 색 — 예: 주황과 분홍
- `{at}` 전환 시점 (선택) — 예: 0:45
- `{dur}` 전환 길이 (선택) — 예: 1초

## B15 분할 화면 (split screen)

- 이럴 때: 여러 사람 반응, 여러 매장·현장 동시 보여주기
- 길이: 1.5~3초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 홍보, 교육 · 업종: 유튜버, 부동산, 뷰티

요청 문장:

```
분할 화면(split screen) 만들어줘. 영상 여러 개를 1개 → 2분할 → 4분할로 퍼즐처럼 열어줘. 영상 파일: {files}.[[ 칸마다 표시: 「{labels}」.]][[ 지속 시간: {dur}.]]
```

칸:

- `{files}` 영상 파일들 — 예: cam1.mp4 / cam2.mp4 / cam3.mp4 / cam4.mp4
- `{labels}` 칸 표시 (선택) — 예: 캠 1 / 캠 2 / 캠 3 / 캠 4
- `{dur}` 지속 시간 (선택) — 예: 5초

## B16 VHS 되감기 (VHS rewind effect)

- 이럴 때: 앞 장면을 다시 볼 때, 과거 회상
- 길이: 1~2초 · 방식: 캔버스 · 재료: 전부 코드
- 용도: 홍보, 교육 · 업종: 유튜버, 음식점

요청 문장:

```
VHS 되감기 효과(VHS rewind effect) 만들어줘. 줄무늬와 색 번짐, 흔들림 위에 되감기 표시와 거꾸로 가는 시간이 보이다가 원래 화면으로 돌아오게. 표시 글자: 「{label}」.[[ 넣을 영상: {file}.]][[ 시작 시점: {at}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{label}` 표시 글자 — 예: ◀◀ 10분 전
- `{at}` 시작 시점 (선택) — 예: 6:30
- `{dur}` 지속 시간 (선택) — 예: 2초
