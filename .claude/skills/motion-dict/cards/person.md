# 인물·후기 (4)

사람을 소개하고 목소리를 전하는 장치.

출처: 모션그래픽 주문 사전 (https://nondev-thinking.web.app/motion/) — 김지백, 한국경영교육연구소 AI ACADEMY «모두의 AI 교실». 2026-11-09 수정본 기준으로 정리.

요청 문장의 `{이름}`은 채울 칸, `[[ … ]]`는 값이 없으면 통째로 빼는 선택 구간이다.

## T16 방송형 이름 자막 (lower third)

- 이럴 때: 강의·인터뷰 시작, 행사 스케치
- 길이: 4~5초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육, 홍보 · 업종: 교육, 병원, 공공, 유튜버

요청 문장:

```
방송형 이름 자막(lower third) 만들어줘. 화면 왼쪽 아래에 이름과 직함 띠가 스르륵 들어와 머물다 나가게. 이름: 「{name}」. 직함: 「{role}」.[[ 넣을 영상: {file}.]][[ 시작 시점: {at}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{name}` 이름 — 예: 홍길동
- `{role}` 직함 — 예: ○○카페 대표
- `{at}` 시작 시점 (선택) — 예: 0:05
- `{dur}` 지속 시간 (선택) — 예: 4초

## B05 캐릭터 이름표 (character name callout)

- 이럴 때: 출연자·직원 소개
- 길이: 2~3초 · 방식: 글자·CSS · 재료: 내 사진·그림 필요
- 용도: 영업·제안, 홍보 · 업종: 유튜버, 음식점, 병원

요청 문장:

```
캐릭터 이름표(name callout) 만들어줘. 인물 옆에 노란 화살표가 그려지고 별명 이름표가 붙게. 얼굴은 가리지 말아줘. 별명: 「{nick}」.[[ 넣을 영상: {file}.]][[ 시작 시점: {at}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{nick}` 별명 — 예: AI 초보 김대리
- `{at}` 시작 시점 (선택) — 예: 0:20
- `{dur}` 지속 시간 (선택) — 예: 3초

## B11 화상 연결 창 (picture-in-picture call window)

- 이럴 때: 인터뷰, 원격 상담·현장 연결
- 길이: 3~6초 · 방식: 글자·CSS · 재료: 전부 코드
- 용도: 교육, 영업·제안 · 업종: 병원, 부동산, 유튜버

요청 문장:

```
화상 연결 창(picture-in-picture) 만들어줘. 오른쪽 위에 「연결 중…」이 뜬 뒤 창이 켜지며 다른 영상이 붙게. 붙일 영상: {guest}.[[ 창 아래 표시: 「{label}」.]][[ 넣을 영상: {file}.]][[ 시작 시점: {at}.]][[ 지속 시간: {dur}.]]
```

칸:

- `{guest}` 붙일 영상 — 예: guest.mp4
- `{label}` 창 아래 표시 (선택) — 예: LIVE · 게스트
- `{at}` 시작 시점 (선택) — 예: 4:10
- `{dur}` 지속 시간 (선택) — 예: 5초

## T04 후기 카드 캐러셀 (testimonial carousel)

- 이럴 때: 홍보 영상, 제안서 영상
- 길이: 6~10초 · 방식: 글자·CSS · 재료: 내 사진·그림 필요
- 용도: 광고, 영업·제안, 홍보 · 업종: 병원, 뷰티, 음식점

요청 문장:

```
후기 카드 캐러셀(testimonial carousel) 만들어줘. 별 다섯 개와 후기 문장이 적힌 카드가 한 장씩 옆으로 넘어가게. 후기는 아래 실제 문장만 쓰고 새로 지어내지 마. 후기: 「{reviews}」.[[ 지속 시간: {dur}.]]
```

칸:

- `{reviews}` 실제 후기 — 예: 후기 1 / 후기 2 / 후기 3
- `{dur}` 지속 시간 (선택) — 예: 8초
